# 可打开项目与实际导出

- `motion-study.ffstudio`：来自实际运行检查的完整项目包，含场景、摄影机、立方体、运动球体、关键帧、时间轴、1 秒正弦波音频，以及已生成的视频素材。
- `motion-study.mp4`：同一项目经后台逐帧渲染和 FFmpeg 输出的真实结果，320×180、24 帧、1 秒、H.264 视频与 AAC 音轨。

在平台点击“打开”选择项目包即可导入。项目名保留生成时的检查时间；ID 冲突时平台创建副本。场景与音频均由本项目生成，无外部素材。此文件是保存/编辑/导出的运行依据，不代表专业制作能力。

对应检查记录见 `docs/research/2026-10-21-runtime.json`。重新运行 `npm.cmd run smoke` 会在 `.local/checks/` 产生新的结果，不覆盖本目录。
