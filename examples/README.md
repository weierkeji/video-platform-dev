# 可打开项目与实际导出

- `motion-study.ffstudio`：来自实际运行检查的完整项目包，含场景、摄影机、立方体、运动球体、关键帧、时间轴、1 秒正弦波音频，以及已生成的视频素材。
- `motion-study.mp4`：同一项目经后台逐帧渲染和 FFmpeg 输出的真实结果，320×180、24 帧、1 秒、H.264 视频与 AAC 音轨。
- `media-edit.ffstudio`：格式 v2 的实际媒体编辑项目，含竖屏画面、有声/无声视频、源入点、切分、1.5 倍音量和完整显示画幅；源声音在不同时间段使用不同频率，便于核对剪辑位置。
- `media-edit.mp4`：媒体项目的实际输出，320×180、48 帧、2 秒、H.264/AAC；前 0.5 秒黑场，中间 1 秒为带原声的竖屏画面，最后 0.5 秒为无声视频。
- `generation-workflow.ffstudio`：格式 v3，包含可编辑的提示词→Seedance 配置，以及同图独立执行的本地时间轴渲染结果。**没有 AI 生成结果**；配置示例需有效账号权限和预算才能执行真实生成。它用于复现参数、图连接、保存和本地输出。
- `animation-curves.ffstudio`：格式 v4，含稳定关键帧、位置 Bézier 曲线和按轴手柄。打开后选择立方体并进入“动画曲线”，可继续编辑、撤销和导出。
- `animation-curves.mp4`：同项目实际后台输出，320×180、36 帧、1.5 秒；红色立方体沿编辑后的非线性曲线移动。此文件无音轨。
- `mesh-edit.ffstudio`：格式 v5，实际完成正面区域挤出、父级非均匀缩放下的世界轴移动、局部旋转缩放，保留 12 个顶点与 20 个三角面。打开后选择立方体并点击“编辑网格”。
- `mesh-edit.obj`：该网格的局部几何，与包内顶点/三角面逐项一致；OBJ 不携带父级、材质或动画。
- `mesh-edit.mp4`：同项目真实后台输出，480×270、12 帧、0.5 秒，无音轨；展示编辑后的静态网格。

在平台点击“打开”选择项目包即可导入。项目名保留生成时的检查时间；ID 冲突时平台创建副本。场景与音频均由本项目生成，无外部素材。此文件是保存/编辑/导出的运行依据，不代表专业制作能力。

`motion-study` 保留 v1 格式，可检查旧项目导入升级。对应运行记录见 `docs/research/2026-10-21-runtime.json` 和 `2026-10-22-media-runtime.json`。重新运行 `npm.cmd run smoke` 或开发服务上的 `npm.cmd run smoke:media` 会在 `.local/checks/` 产生新的结果，不覆盖本目录。
