# 多键选择与原子时间编辑

具体问题：烘焙或精简动作后，怎样选中一组键，围绕指定时间平移、伸缩或复制，并让内部曲线、稳定身份和撤销历史一起变化？如何避免按键依次移动产生临时撞帧或部分保存？

重读 REA [README](https://github.com/morluto/rea)、[安装要求](https://github.com/morluto/rea/blob/main/docs/installation.md)、[MIT 许可](https://github.com/morluto/rea/blob/main/LICENSE)。本地 rea-agents 6.7.0、MIT 保持不变；当前 main 文档要求 Node 22.23.4+、24.22.1+ 或 26.12.1+，本机 Node 24.20.0 不满足新的 24.x 要求。此单元研究公开交互与本仓库运行，不需要原生反汇编引擎；未升级 REA、未安装新引擎、未声称执行 REA 动态分析。

## 2. 输入与操作

- 先启动现有系统，运行原动画集成流程，确认单键/手柄拖动、历史、项目恢复与真实视频输出仍可用。
- 在同一产品中导入原创“节奏方块”作品：位置 Hermite、四元数 SLERP、缩放线性共三轨 12 键，源时间为 0/6/12/18 帧。
- 用鼠标框选中间两键，Shift 增减选择；与时间轴共享选择并跨到四元数轨。把中间键平移 6 帧与末键冲突，分别从 UI/API 确认原子拒绝。
- 选择对象全部 12 键，先拖动并 Esc 取消，再拖动两帧且故意在垂直方向移动鼠标，确认多键只改时间。撤销/重做，再以所选首帧为枢轴应用 1.5 倍时间与 1 帧偏移。
- 将所选键复制偏移 36 帧，得到 24 键；删除副本、撤销，A 全选当前曲线、Delete 删除整轨、撤销并重载。
- 比较源时刻与映射后时刻、复制时刻的 PNG；实际生成 H.264 影片。原生动画 GLB 导出/校验/重导入，恢复 glTF 不携带的背景/环境光后比较画面；导出和重开完整项目包。

实际结果与项目/任务标识由本目录 `2026-10-25-key-editing-*-runtime.json` 保存。内部采样检查确认正向时间伸缩保留 Hermite、SLERP、STEP、smooth、自动/向量/自由/对齐 Bézier 的相邻已选段；部分选择的自动手柄先取原有效值再固定。SQLite 跨重启撤销恢复整组键，而不是只恢复最后一个键。

## 5. 已确认事实

命令以 `(trackId,keyId)` 为选择身份，变换保留 ID，复制由命令携带全新 ID。先从原轨读出全部输入，生成最终键集合后检查碰撞，因而从 0/6/12/18 整组移到 6/12/18/24 不会产生中间冲突。任何受影响轨失败都不写项目。选择只在 UI 内保存；项目修订变化取消未提交拖动。

时间变换是 `f' = pivot + (f - pivot) * scale + offset`。Bézier 的时间偏移乘倍率、数值偏移不变；Hermite 每帧导数除以倍率。自动/向量手柄取移动前有效值并固定为自由手柄，手动对齐关系保留。四元数切线是分量导数，不能当作旋转四元数归一化。GLB 兼容曲线继续走原有原生导出路径。

## 6. 推断与依据

对正倍率的仿射时间映射，曲线两端时刻及其时间控制点同变换，或 Hermite 段跨度与导数反向缩放，能保持段参数化后的数值。采样和独立播放器支持当前实现，但不是浮点形式化证明。该推断只适用于仍相邻的已选端点；未选邻居、交叉或复制插入造成的新段会改变。

## 7. 未知与覆盖限制

基础支持，未评为专业可用、性能达标或完整。GUI 多键范围为当前对象、当前场景动作的 TRS/四元数轨；IK 单值支持同一批量命令，IK 专用面板仍为单键编辑。XYZ/XYZW 的时间成组，手柄独立多选、跨对象图形选键、剪贴板跨动作粘贴、波纹编辑、值域批量变换、负倍率时间反转、循环外推仍未实现。

选择不写入项目包。批量操作不延长时间轴、不修改片段调度、层窗口或其他动作。更改部分曲线会改变边界插值；复制也可能改变原键与新键之间的连接。自动手柄固定后可手工改回自动，但可能改变边界曲线。没有提供世界接触或蒙皮姿态不变保证。原生 glTF 不携带背景、环境光、时间轴与工作流；Bézier 等非兼容曲线仍使用既有采样并提示近似。

每次最多 20 万选择引用，每轨最多 10000 键，帧 0…1000000、正倍率 1e-6…1e6；最终数值仍受原模型约束。精度塌缩或切线溢出拒绝，不截断。尚未对最大规模交互做性能达标承诺。

## 8. 自主实现规格与后续

沿用 v17，新增严格结构化 `keys.transform`、`keys.duplicate`、`keys.delete`。预演和服务端使用共用纯函数，不依次调用单键命令；一组成功编辑进入现有 SQLite 事务/Revision，失败不改变修订。复制新 ID 显式随命令记录，支持 Agent 审阅恢复。UI 框选只取当前可见轴的键点，Shift 增减/追加，A 选择当前曲线、Alt+A 清空，中键平移；多键拖动只更改时间，Alt 保留子帧，Esc/pointercancel/修订变化取消。

下一项优先补上对象重设父级时保持世界变换的公共基础，明确非均匀缩放、剪切、动画和驱动状态的边界。IK 图形多选、跨对象编辑、旋转解缠与循环外推继续保留；专业建模、UV、材质、物理、合成、媒体和 AI 等完整目标没有缩减。
