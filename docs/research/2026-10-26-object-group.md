# 场景多对象选择与成组编辑

具体问题：场景中有父子、不同父级、动画频道和驱动时，怎样用共同选择和活动对象进行成组空间编辑，使父子不重复变换、预览与提交一致，并能整组撤销和导出？

## 2. 输入和操作

先启动现有 0.23 服务并检查健康状态。原创场景使用两个旋转装配组、一个嵌套子方块，以及位置 Hermite、四元数旋转两条动画。通过层级列表 Shift 增减、活动对象选择器、视口点击/Shift 和原点矩形框选选择三个对象；A 全选可见对象、Alt+A 清空。

实际拖动共同手柄，先 Esc 取消，再沿世界 X 移动约 0.5 米，比较拖动中的画面、保存后画面及所有选中世界矩阵。再以活动对象原点执行平移、Z 旋转 30°、均匀放大 1.2；以各自原点旋转，核对各自世界位置后撤销。构造局部剪切操作和重复 ID 请求，确认没有新增修订。

通过界面整组重设父级、隐藏和 Delete，并整组撤销/重做；重载确认持久数据与临时选择分离。导出 PNG、原生动画 GLB、真实 H.264；GLB 重新导入，补回标准不携带的背景/环境光后比较六个时刻。完整项目包重开保留对象和动画；切换到同实体 ID 的导入副本清空旧项目选择。

## 5. 已确认事实

选择是临时有序 ID 数组，最后一项为活动对象；项目切换即清空，即使导入副本保留相同实体 ID。刷新会剔除已删除/移出场景的对象。列表和视口共用该集合；切换到曲线、成片、基础姿态或组件编辑时收敛到活动对象。在曲线、成片、基础姿态中继续 Shift 点击列表也保持单对象；曲线/成片实际操作已检查，避免在单对象编辑上下文保留隐藏批次。

entities.transform 保存选择、activeId、frame、layers、pivot 和世界位移/旋转/倍率。共同枢轴取所有选中原点的算术均值；活动枢轴取指定选中对象原点；各自模式对每项用自己的原点。每项 delta 为 T(位移)×T(枢轴)×R×S×T(-枢轴)。目标 world=delta×oldWorld。父级若位于另一个选中祖先下，先用最近选中祖先的 delta 更新旧父级世界矩阵，再反算当前节点的物理局部及 localBasis。共同 delta 下，选中子节点通常不需要新键；各自枢轴可以通过修改子频道抵消父级的附带位移。

已有动画频道仅写当前场景动作的当前帧键，保留旧键 ID、插值/切线；未动画频道改基础值，其他动作不变。纯平移保留原镜像缩放和多圈 Euler。四元数写入靠近原符号半球，Euler 从等价分支取靠近原角度的表达。姿态只能由有限 TRS 表达时才提交，位移矩阵验收绝对阈值 1e-6 米，其他分量相对阈值 1e-8。

## 6. 推断及依据

对共同 delta，inverse(delta×parentWorld)×delta×childWorld 会抵消共同变换，因此无需对子频道再叠加一次。各自 delta 不同，则由目标 world 与新父 world 反算子频道，达到各自原点预期。矩阵/像素/持久化检查支持当前实现，不是形式化浮点证明或全部驱动组合的证明。

拖动预演通过同一命令草稿、完整校验和场景求值生成临时矩阵/蒙皮；松开才提交一次。Esc、帧/修订/选择/枢轴变化取消。原权威项目在预演中不变；选择标记只添加到编辑器渲染器。批量删除先合并选中子树再检查外部引用，避免逐项删除时内部引用导致顺序依赖或部分删除。

批量显示/隐藏使用 entities.visibility 单命令，设置所选实体自身的 visible 标志，父级继承仍按既有求值规则。选择 101 项时仍是一次原子操作，不受普通命令批次最多 100 条限制；未选实体的显式标志不改，非法/重复 ID 拒绝整次操作。

## 7. 未知和限制

基础支持，未评为专业可用、性能达标或功能完整。世界轴、源场景当前动作/帧；不是镜头时间轴整体重排。已动画频道写一帧会改变邻接插值，未动画频道改基础值会影响整个动作。支持的数值/选择仍受模型及最多 2000 项限制；拖动会做完整草稿求值，大场景性能尚未达标测量。

选中的有效约束、非零 IK 关节、启用的动作层预览和直接蒙皮对象会说明原因并阻止成组频道编辑；可先匹配 FK、关闭层预览或移动骨架/共同父级。未选驱动造成目标偏移时最终验收拒绝整批。非均匀世界缩放/旋转要求原频道出现剪切时拒绝，不静默近似。直接蒙皮节点的 TRS 按既有模型并不移动加权外形，不能把它当作骨架移动。

对象矩形框选按可见对象原点投影，不是网格遮挡选择；父级隐藏会排除其后代。Shift 加选、Ctrl/Cmd 减选；点击使用 Shift/Ctrl/Cmd 增减，最后加入者活动。没有范围行选、套索、集合、实例、层级拖放、完整层级复制、局部轴/自定义坐标系/包围盒枢轴、吸附或比例编辑。共用枢轴包含被选子节点，不是仅根节点平均。批量父级操作将每个所选对象附加到同一父级，可能把原父子变成同级，界面已有说明。

## 8. 自主实现规格及后续

沿用 v18 模型，无需为临时选择或命令参数改变项目格式。新增严格结构化命令走已有原子草稿、最终模型校验、SQLite 单修订历史；界面和 Agent 使用同一路径。UI 独立采用列表多选、活动对象下拉、均值/活动/各自枢轴、数字变换与批量父级/显示/删除；没有复制参考产品源码或视觉资源。

下一单元研究完整层级复制：在一次事务中复制所选子树并重映射内部父级、约束、骨架/蒙皮、动作与层引用，同时定义外部引用和共享数据策略。现有单对象复制不能代替此功能。专业建模/绑定/UV/材质/物理/合成/媒体/AI 等完整目标继续保留。
