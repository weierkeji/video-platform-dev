# 误差约束关键帧精简：连续区间检查与完整新动作

具体问题：怎样减少密集动作中的键，同时保留两键之间的曲线变化、跳变与区间外形状？位置、欧拉角、四元数和 IK 单值参数能否采用明确的容差，并通过同一事务保存为新动作？本单元为基础支持，不是最少键求解或专业动画优化器。

## 5. 已确认事实

精简读取指定场景/动作的原始变换和 IK 参数轨道。每轨复制完整时间域；只在选择范围内删键，不移动时间，不裁切首尾。源轨道和源键 ID 不变，新动作/轨道/键使用新 ID。统一 `action.reduce` 事务在服务端重新计算，失败不保存部分结果；审计保留容差/范围。启用仅切换场景默认动作，不停用基础偏移、层、约束或 IK。镜头/片段的动作覆盖仍优先。

首尾、范围外及范围跨越相邻键、真正的 STEP 跳变两侧、Float32 时间保护邻域被固定。缩放单轨控制点包围区间穿越零值、IK 影响穿越 0/1 时保留原段；这是保守判定，可能多保留。多层组合产生的阈值不在此保证内。保留的 Bézier 段固定原有效手柄，避免删除邻键改变自动/向量手柄；固定后超格式范围则保留整轨。

## 6. 推断及依据

只检查原键值不足以发现 Bézier/Hermite 内部峰值。因此自主规格比较整个源段与候选直线的差：数值曲线转为时间/数值的三次 Bernstein 控制点，逐控制点减去候选线在该时间的值，取分量绝对值上界。位置/缩放合成欧氏范数；欧拉 XYZ 未折回差之和约束旋转路径并保留绕圈；单值用绝对差。控制点凸包性质使数学曲线整段受界，不依赖固定探测间隔。

四元数使用实际 SLERP/近邻归一线性/Hermite 原始路径。区间中点、原始路径导数上界和区间内模长下界，给出归一化路径的旋转半径；加上候选半径和中点角差后判断整段。无法确认则二分，达到深度/总预算就保留源段。这里是自主数值分析实现与浮点余量，不声称与 Blender 内部算法相同，也不是经过机器证明的浮点区间算术库。

## 7. 未知项和限制

- 容差针对原始局部通道。父级、基础偏移、层混合、限角、IK、蒙皮和接触可放大最终差异；没有一般世界空间、脚底接触或图像误差保证。本作品 PNG/顶点检查只说明该作品。
- 采用保守分段，不能保证最少键；输出替换段为线性，保留段维持原插值。数值上界偏大或四元数路径难以确认时可能完全不减键。极小容差、非单位原始四元数和边界邻域尤其保守。
- 0 容差表示整类通道不删键；上限 20 万输入键、100 万次检查、四元数细分深度 20。浏览器分析可取消并有 60 秒超时，服务端重算有工作量上限但没有独立取消任务。未作大规模性能达标认定。
- 精简不会修复原烘焙/重定向漏采的帧间运动。原生 GLB 仍受已有插值/驱动表达限制；不能表达时应先烘焙，烘焙输出可能再次增加键数。glTF Float32 输出会引入另行的量化误差。
- 没有比例删键、世界姿态优化、接触锁定、自适应烘焙或可逆覆盖原动作；完整 NLA/绑定/材质/物理/合成/AI 等范围保留。Seedance 没有凭据/预算，未作真实生成。

## 8. 自主实现规格与下一项

项目沿用 v17；容差、范围和动作 ID 进入严格命令结构。worker 仅返回统计，保存由统一事务权威重算；每轨报告前后键数和本地误差上界。分析结果只对同一项目修订有效，参数变化清除；关闭/取消终止 worker。支持成组位置、Euler、四元数、缩放及 IK 单值轨，源与输出均可继续编辑、撤销、重开和交换。

下一单元研究误差驱动自适应动画烘焙：怎样对层/约束/IK 的最终求值按变化补样，同时明确跳变保护、样本预算与观测误差的限度；避免把有限探测当成通用连续时间证明。完整产品目标继续保留，不将当前基础能力计为全目标完成。
