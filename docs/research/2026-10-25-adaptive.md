# 自适应动画烘焙：最终局部姿态补样与输出条件

具体问题：固定步长可能漏掉对象层、IK 和约束合成后的快速变化，怎样根据实际求值继续补样？哪些区间属于时间量化的跳变保护邻域，哪些区间确实没有满足目标？分析、保存和 GLB 输出如何使用同一判定？本单元达到基础支持，有限探测不等于连续时间证明。

## 2. 输入与操作

原创 `scripts/adaptive-fixture.ts` 延续 IK 雕塑、影响/极向参数曲线与倒放往返参数叠层、末端跟随约束、摄影机朝向约束，增加三键 Hermite 摄影机平移。范围 0–48 帧，初始步长 8，位置分量容差 0.001 米、旋转 0.1 度、缩放分量 0.001，最小补样间隔 0.001 帧。

通过真实 glTF 面板启用“按探测误差自适应补样”，修改容差精度、分析和取消 worker。最小间隔大于步长必须拒绝；设为 8 时分析显示未达标，保存、导出和直接命令 API 均拒绝且不写修订。恢复 0.001 后直接输出自适应 GLB，另存/启用新动作，撤销/重做/重载；原生动画与静态 GLB 导出后由界面重导入，选择新 clip 制作镜头。影片任务提交后切换场景动作，核对固定快照，最后导出和重开项目包。

## 5. 已确认事实

初始网格沿用原始关键帧、层边界和 Float32 跳变两侧保护。每个候选区间探测 1/4、1/2、3/4 和 `(1±1/√3)/2` 五个内部时刻，读取完整层/约束/IK 求值，与候选 LINEAR/SLERP 或保持曲线比较。任一局部通道超目标时，在可表示的 Float32 中点补入真实姿态，然后重新检查子区间；所有输出通道共享同一非均匀网格。

位置/缩放沿用烘焙的最大分量差，旋转使用归一化四元数角距离。报告只用最终叶区间累计最终误差，同时单独记录原网格误差、总采样工作量、已完成探测和未完成区间。跳变保护段仍实际探测并单列差异和最大跨度，但不参与非跳变段达标判定。

浏览器分析可返回未达标结果；`action.bake` 服务端权威重算后通过同一输出条件才保存，GLB 按钮在序列化前检查相同条件。启用结果沿用完整场景烘焙语义：切换场景默认动作并停用该场景的基础偏移、对象层、约束和 IK，保留原数据与历史；仅保存不启用仍保留当前驱动。

## 6. 推断及依据

最终姿态依赖非线性约束和 IK，源曲线的控制点界不能直接当作合成输出的误差界。因此采用有限探测驱动补样，明确区分“已探测达到目标”和“连续区间保证”。全部轨道共用网格使同一时刻只进行一次全场景求值，并保留父子局部关系。动态插入时刻重新量化和检查顺序，避免时间重合。

比统一缩小所有间隔更少的键是该作品的实测结果，不能推断所有动作都会更小或更快。检查中的独立密集对照与蒙皮/摄影机输出增加证据，但不转化成一般世界空间精度承诺。

## 7. 未知项和限制

- 初始步长控制初始最大间隔，有限探测可能漏掉探测点之间的短暂脉冲/高频运动。父级、皮肤、接触会放大局部差异；没有通用连续时间、世界空间或像素误差界。
- 最多 10000 时刻/轨、20 万输出键、细分深度 20、约 200 万节点采样。最小补样间隔仅限制新插入，不删除初始网格中更近的边界键。固定步长路径也新增节点采样工作上限，超出时明确拒绝。
- 自适应预算用尽时，已产生的每个键都有真实姿态；无法完成的区间单列为未检查，不把部分测量记作通过。初始网格本身超预算直接拒绝。不是执行任意求值代码的超时沙箱，也未证明最坏耗时；浏览器仍有 60 秒超时/取消，服务端计算有上述工作量限制。
- 姿态必须能由局部 TRS 表达；剪切/非有限变换和非法关键帧仍拒绝。原烘焙的跳变时刻量化近似继续存在，未承诺捕获所有组合阈值/奇异点或解析物理仿真。
- 重定向仍为独立固定步长采样，不静默忽略自适应选项。没有世界扁平化、接触修正、最少键优化或完整 NLA；结果可继续用 0.20 精简，但精简有独立的局部误差含义。Seedance 仍无凭据/预算，未调用生成。

## 8. 自主规格与下一项

BakeOptions 增加可选 adaptive，包含正数位置分量/旋转/缩放分量容差和最小间隔，旧命令不带字段仍是固定模式；项目格式仍 v17。参数进入统一审计和原子保存，不新建独立工程。状态区分达标、超容差、未完成检查及具体限制；分析不写修订，未达标输出不持久化。输出可继续编辑、撤销、恢复、原生 GLB 交换和任务渲染。
