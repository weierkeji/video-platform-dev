# 共享几何与材质的用户管理

具体问题：网格或材质被多个对象使用时，怎样先看到修改会影响谁，再让一个对象或一个选中组独立编辑，同时保留权重、绑定、UV、图片和动画引用？

基线 0.25 已提交推送 b2f6420 且工作树干净，继续启动现有平台。原创两套可见蒙皮造型与其他场景的隐藏造型共用几何和材质，含 UV0/UV1、权重和原创 16×16 方格 PNG。实际查看/跨场景定位使用者、选择本场景两对象、勾选资源、整组解除外部共享、撤销重做，再进入右侧网格全选组件并单独解除共享。确认组件编辑退出后改底部顶点 X=-0.85、材质 #55b8cf，重载、保存恢复项目包、导出动画 GLB 并重导入、实际生成 MP4。

## 5. 已确认事实

数据用户是项目内所有引用该资源的实体，不能仅统计当前场景或可见对象。几何/材质彼此独立，几何上的关节索引配合实体绑定解释；克隆几何须逐项保留索引、权重、UV 与法线，实体绑定不用重算。材质图片引用仍指向既有 Asset，解除材质共享不意味着复制图片像素。

## 6. 推断及依据

纯复制资源并改实体引用应保持所有时刻的外形与材质；之后编辑副本只影响引用副本的对象。组方式按每个源数据生成一份副本，可保留所选对象内部的原共享关系。逐对象方式必须让每项独立；当原资源的全部用户均被选中时可保留一个用户使用原数据，避免产生无用资源。上述推断已由选定场景的原始数据、顶点/引用、历史及六时刻画面支持；没有将有限采样视为所有专业资产或性能证明。

## 7. 未知与限制

本单元不提供集合实例、资源库跨项目链接、动画数据块链接、图片像素独立化或自动清理孤立资源。先覆盖网格实体的几何/材质；其他专业数据类型仍保留在全范围目标中。大规模资源性能未达标。

## 8. 独立规格

entities.data.isolate 接收唯一网格 ID、geometry/material 资源集、individual/selection 模式和 UUID batchId；一次事务、最终模型校验、整组撤销，无格式迁移。selection 模式仅在该源资源还有未选用户时复制一份供选中组使用；individual 模式为每个共享用户分开，全部用户已选时保留一个原资源用户。已经满足独立要求的项不复制，无实际变化则明确拒绝，不制造空修订。新 ID 从请求批次确定，容量或 ID 冲突整次拒绝。

界面显示资源名称与项目内所有场景的用户数/名单，可定位对象或选中本场景全部共享用户；为选中网格选择资源类型与独立方式，显示即将新增的资源数量后执行。几何变化会退出旧组件编辑，重新选择新几何；实例外形、基础姿态、绑定、动画/约束与图片引用保持。全平台目标继续推进，不把此功能称为完整资源系统。
