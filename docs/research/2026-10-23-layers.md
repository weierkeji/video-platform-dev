# 对象动作层、权重与姿态混合

## 1. 研究对象与版本

具体问题：同一对象的多个动作如何依次贡献到位置、缩放和旋转？缺失通道、基准姿态、权重边界及层时间如何影响结果？编辑混合结果时怎样防止误写原动作？

公开行为参照 Blender 4.5 LTS NLA 手册和 4.4 Python API 文档。产品实现为 Frameforge 0.10、格式 v10，Three.js 0.180.0 负责基础四元数/显示。REA 6.7.0 保留原有研究安装，本单元无需额外分析引擎，没有调用 Blender 可执行文件或 bpy。

## 2. 输入与操作

检索官方 NLA sidebar 的 Replace、Combine、Influence、Blend In/Out。阅读公开检索正文；此前直接抓取手册返回工具 402，未绕过访问限制，也没有原生 Blender UI 捕获。

平台中创建原创红色长方体、父对象、摄影机和三个可计算动作。通过真实 UI 添加五层：父级位置替换/增量、子级旋转缩放替换/旋转增量、摄影机位置增量；设置 12 帧淡入、8 帧淡出及通道选择。执行顺序调整、禁用/删除/撤销/重做、源动作原值编辑、动作删除保护、重载；正放及倒放镜头组成 48 帧影片。提交渲染后更改/删除层，再核对固定快照输出、项目包重导入和当前帧 GLB。

## 3. 实际输出

官方文档说明堆栈按影响权重组合，替换模式插值之前结果，Combine 按通道类型使用不同运算，四元数以整体参与。此处只有文档证据，不推断 Blender 内部算法实现。

平台开发入口实际通过集成检查。8 个时刻 0/6/12/23/24/28/35/47 对应源帧 0/6/12/23/47/43/36/24，手算姿态参考与产品 PNG 平均像素通道差均为 0，PNG 对 MP4 为 0.413–0.434/255。输出 480×270、48 帧、2 秒影片，无页面错误。参考姿态不使用本平台的轨道取样/层求值，但显示仍复用 SceneRenderer 和 Three.js，不是第二个独立渲染引擎。

正式入口再次通过相同操作和输出检查。65 项核心检查、类型检查和构建通过，主包 961.51 KB（有体积提示，非性能达标）。旧镜头调度、动画交换及通用保存/带音频导出/任务幂等取消重试在正式入口回归通过；旧动画 GLB 校验 0 错误/警告/信息。没有重跑所有历史网格/贴图/媒体脚本。

首次检查在任务完成后用一次 undo 恢复层，实际撤销了新登记的产物历史，断言失败；改为显式恢复层设置，保留产物登记，再完整通过。没有修改产品历史语义或放宽超时。

## 5. 已确认事实

动作层进入统一项目、批次命令、保存历史及任务快照。相同对象可以复用同一或不同动作，通道只对该对象取样；缺失/空轨道不贡献基础值。每次求值重新从对象基础姿态开始，不向别的对象或镜头泄漏结果。当前帧 GLB 可保存混合姿态；有启用层的场景导出原始动画 GLB 会明确拒绝。

## 6. 推断与设计依据

堆栈替换允许用一个全权重基础结果和后层淡入实现动作间过渡。它不等于多个权重归一化后的同时混合；若两层都淡出/淡入，基础结果仍可能参与。此实现明确采用有序堆栈。

增量需避免对已经有偏移的基础姿态重复施加绝对位置；本平台选用对象持久化基础姿态为参考。缩放用线性差值，支持负缩放且不需要对比例取幂，区别于 Blender Combine 的比例规则。旋转统一转换四元数，避免直接对 Euler 分量做增量而依赖绕轴顺序。上述是自主规格，不声称与 Blender NLA 数值等价。

## 7. 未知与覆盖限制

没有完整 NLA 轨道视图、拖动层、自动交叠、独奏、权重 F 曲线、归一化多动作混合、乘法缩放、用户参考帧、骨骼/蒙皮/重定向或旋转解缠。四元数采用最短弧，无法表达额外整圈；多个增量旋转依赖层顺序。缩放插值仍可能经过零，引发奇异几何变换。未做大型层堆栈性能达标证明。

动作层烘焙为动画 GLB 尚未实现；下一项研究采样区间、离散边界、精度和误差提示，保持原始项目可编辑。禁用层导出仅表示导出原始动作。完整目标不因此缩减。

## 8. 自主实现规格

`Project.animationLayers?` 最多 512 层，每对象最多 64；数组先后即同对象混合顺序。层包含 ID/name/entityId/actionId（null 为项目轨道）、enabled、replace/additive、weight 0…1、position/rotation/scale 通道、start/duration/sourceIn/playback、fadeIn/fadeOut。同场景引用，通道不重复，淡入+淡出不超过时长。层时间可小数，窗口 `[start,start+duration)`，最大终点 100 万帧；范围/速度/原始时间约束复用镜头规格。

先求镜头选定基础动作，再遍历此对象的层。以映射后的场景源帧计算层有效权重：窗口内 `weight × min(1, elapsed/fadeIn, remaining/fadeOut)`，0 长度淡入/出对应项为 1，窗口外 0。层源帧为 `sourceIn+(sceneFrame-start)×rate` 再按保持/循环/往返折回。源范围不等于层窗口，改变时间不改动作键。

替换：位置/缩放线性插值，旋转最短弧 SLERP。增量：向量 `current + weight × (sample-rest)`，旋转 `current × SLERP(identity, inverse(rest) × sample, weight)`，结果归一化；旋转通道同时涵盖 Euler 和 quaternion，单动作仍不允许两者共存。只处理存在的非空动画通道。

命令 layer.add/update/delete/move；删除被层引用的动作拒绝，删除对象级联删除其层，复制对象复制层并分配新 ID。所有层设置可撤销、保存并进入固定快照。v9→v10 只升级格式号，新字段可选。

原动作编辑用 evaluatedBaseTransform；层预览启用时隐藏有启用层对象的变换手柄，可关闭预览编辑源动作。数值/记键/曲线始终使用原动作结果。切换预览取消未提交拖动。此开关为编辑视口临时状态，输出持续使用完整层求值。
