# 2026-10-22：正式供应商接口与可恢复生成任务

## R6：生成任务中断后，怎样避免重复请求并取得可编辑产物？

1. 对象/版本：火山方舟 Seedance 官方创建/查询/取消文档，读取日期 2026-10-22，文档覆盖 1.0 pro/pro fast、2.0 系列及 2.5；本平台 0.3、Node 24.20.0、Chrome 155.0.8059.82。模型 ID 由运行者按账号权限指定，不把文档示例当作已获访问权限。
2. 输入/操作：查阅 HTTP 方法、鉴权、输入结构、模型参数范围、状态、链接期限和取消语义。官方 Markdown 路径及部分页面抓取失败，转为可访问的官方文档搜索内容。实现服务端适配后，使用明确协议夹具检查提交、查询、取消、网络失败与重启；真实浏览器编辑生成图、参数并重开和导入项目包。未发送真实生成请求。
3. 实际输出：20 项核心检查通过；创建响应 ID 先持久化，重启已知 ID 只查询，未知提交标记中断；查询中收到取消请求不会丢失，只有查询确认 cancelled 才标取消。真实浏览器显示 missing-credentials，生成按钮禁用，API 拒绝提交且任务数保持 0。同图的本地渲染输出生成真实 MP4。协议成功夹具使用仓库既有 MP4，经过下载流、真实 ffprobe 和原子素材登记，不声称由外部模型生成。
4. 证据：[官方创建接口](https://console.volcengine.com/ark/region%3Acn-beijing/docs/create-video-generation-task-api)、[官方查询接口](https://console.volcengine.com/ark/region%3Acn-beijing/docs/get-video-generation-task-api)、[官方取消/删除接口](https://docs.volcengine.com/docs/ark/cancel-or-delete-video-generation-tasks-api)、[官方教程](https://docs.volcengine.com/docs/ark/video-generation-tutorial?lang=zh)。本地证据为 `tests/generation.test.ts`、`scripts/workflow-smoke.ts`、[浏览器运行记录](2026-10-22-workflow-runtime.json)、`examples/generation-workflow.ffstudio`。
5. 确认事实：官方 POST 创建异步任务，GET 查询，Bearer API Key 鉴权；DELETE 对 queued 取消，对已完成/失败/超时记录删除，running 不支持。任务记录保留 7 天，结果链接有效 24 小时；2.5 结果有下载次数限制。参数能力随系列不同，首尾帧可用公开图片 URL、Base64 或供应商资产 ID。本平台本轮只实现库内图片直传。
6. 推断及依据：公开创建契约未提供本平台可验证的跨网络重试幂等保证，所以只将本地 requestKey 用于本地去重，不将其宣称为供应商去重键。请求结果未知时人工核对关联 ID，比重新 POST 更符合避免重复计费的目标；这是独立调度设计。结果 URL 有期限，因此成功后及时下载到本地资产系统。
7. 未知/限制：未验证账号鉴权、模型权限、实际参数兼容、远端计费、生成质量或网络实况。协议夹具不是供应商服务行为证明。排队到完成可能与 DELETE 产生竞态，删除后的查询失败不被解释为已取消。缺少回调、全模态参考、编辑/延长、尾帧导入、多节点产物传递、供应商列表核对 UI、金额预算控制及分布式调度。模型系列由用户显式选择并与 ID 对应，服务端仍以供应商校验为准。
8. 独立规格：项目 v3 保存生成参数和参考 Asset ID；结构化命令支持撤销/审计/恢复。GenerationJob 保存不可变请求、项目快照、工作流输出和远端 ID；凭据只从服务端环境读取。异步队列独立于本地渲染，5 秒轮询，单轮等待 60 分钟后允许恢复。仅官方 API 地址和受限 HTTPS 产物域名，下载不传密钥，流式限 50 MB/120 秒；真实媒体探测后将 Asset、Artifact、Revision 和任务成功状态一并提交。

## 配置与使用边界

`ARK_API_KEY` 为服务端密钥；`STUDIO_SEEDANCE_MODEL` 为可选默认模型 ID；`STUDIO_ENABLE_PAID_GENERATION` 默认 false。运行者应先在供应商账户设置合适预算，再启用付费生成；平台当前没有金额限额或成本估算。工作流界面保存模型 ID、系列、2–30 秒范围内受系列约束的时长、分辨率、画幅、种子、原声/水印和可选首尾帧。1.0 请求不发送 generate_audio。

首尾帧当前限定 PNG/JPEG/WebP、每张 20 MB、边长 300–6000、宽高比 0.4–2.5，实际文件须匹配保存的哈希。限制属于本地适配范围，不宣称覆盖供应商全部输入能力。任务与签名产物地址不装入便携项目包，配置和登记后的素材随包保存。临时链接不输出到日志；错误仅显示受控说明/HTTP 状态。

没有增加第三方依赖，没有复制供应商 SDK、界面或私有接口。外部模型及媒体基础组件分别属于其供应商和原作者；平台自主实现参数组织、调度、状态持久化和结果处理。
