# 架构与数据语义

TypeScript 同构内核、React UI、Three.js 显示层、Node HTTP 与内置 SQLite。原仓库只有 README 与 MIT LICENSE，未发现 AGENTS.md 或既有数据。选择这些组件让编辑、脚本和后台渲染共享校验及逐帧求值，不依赖 Blender 运行时。REA 仅用于研究。

## 数据模型

`Project` 包含 `Asset`、`Scene`、`Entity`、`Geometry`、`Material`、实体上的 `Light` / `Camera`、`AnimationAction` / `AnimationTrack` / `AnimationLayer`、`Shot`、`Timeline`、`Workflow`、`Artifact`。`GenerationJob` / `Revision` 在同一数据库通过 projectId 和修订号关联，避免编辑反向改变运行任务。

- ID：UUID 创建，项目内命名对象唯一校验；引用不依赖名称。
- 空间：右手系、Y 向上、米；本地位置、XYZ Euler 弧度、非零缩放；v8 可选单位四元数 XYZW 优先表示姿态，求值时生成 Euler 供属性与空间编辑使用，Three.js 显示直接使用四元数。UI 角度显示为度。父子关系限制同场景，子对象继承父变换/可见性。重设父对象保留本地变换，不保留世界姿态。
- 时间：零起点；片段边界/长度仍是整数帧，区间 `[start, start + duration)`，动画键允许小数帧。1–120 整数帧率，尚无 24000/1001。媒体源帧=`sourceIn + timelineFrame - start`，镜头可选恒速和范围映射，详见下文。改帧率保留帧位置，秒数变化。导入动画秒时间乘项目 FPS，切线除 FPS；导出反向转换。媒体/镜头插入吸附最近整帧，分数播放头不可切分片段。
- 摄影机：透视垂直 FOV、有限 near/far；镜头引用摄影机实体。v6 可选 aspect 固定投影比例，缺省随输出尺寸调整；无自动信箱边框。
- 颜色：sRGB 输入、Three.js 线性着色、ACES 映射、sRGB 输出；v6 材质可选 linearColor 保存原始线性 RGB，优先于 color 的 8 位显示值；修改颜色选择器会移除旧 linearColor。支持 opacity、OPAQUE/MASK/BLEND、alphaCutoff、emissive、doubleSided、flatShading，缺省仍为平面双面不透明。v7 基础色/自发光贴图按 sRGB，其他贴图按线性数据；alpha 为线性值。无 OCIO 或专业校色保证。
- 几何：本地顶点/三角面，v5 允许无面、孤立顶点及空网格。边是三角面的规范化索引对；没有独立线段或多边形数据。修改几何后，预览和导出读取相同数据。线性四分三角形不是平滑曲面细分。
- 素材：SHA-256 内容寻址，ffprobe 读取真实流信息；便携包 base64 嵌入素材并校验哈希。没有压缩包或缺失媒体重定位流程。
- 画幅：Clip.fit 为 contain/cover/stretch。默认 contain 保持完整画面、空白处显示低轨；cover 居中裁切源画面；stretch 拉伸。预览和导出共用矩形计算。
- 数据版本：schemaVersion=13；显式拒绝未知格式。v1 在副本上升级，每个旧片段设为 stretch，保留音量；v2–v12 保留已有设置。v1–v3 关键帧按轨道内原时间派生 `legacy-key-<frame>`，在历史/任务快照间保持一致；v4 及以上的键 ID 原样保留。v6–v13 新字段均可选；v11→v12→v13 修改格式号，并沿用机器精度绑定矩阵末行规范化。新关键帧为 UUID，ID 在轨道内唯一；完整身份是 `(trackId,keyId)`。复制动作创建新轨道/键 ID。不改原项目文件。数据库启动时先校验全部待迁移数据，`VACUUM INTO` 备份完整库，再在事务内升级项目、撤销历史、版本与任务快照，并写入 `schema_migrations` 的版本、备份名和计数；不增加用户编辑修订。夹具覆盖升级、原库备份和历史恢复。
- 生成：工作流节点保存参数和首尾帧 Asset ID，通过统一命令编辑并验证引用；被引用图片不可删除。提交时保存解析后的 GenerationRequest、Project 快照、工作流/输出节点和 requestKey；后续编辑不影响已提交请求。

## IK 链求值（0.14）

可选 Project.ikChains（v13），最多 128 条，直接父子路径 3…33 节点，末端是最后节点原点。记录目标/可空极向、极向角、开关、影响、迭代和容差。ik.put/delete/create 使用统一事务；create 用当前帧姿态生成两个独立控制对象。删节点时保护任何仍保留的链引用，整链删除才移除链记录；单对象复制不复制整条 IK。

constraints.ts 先校验普通对象依赖，再将启用且影响非零的整条链收为一个写入组，收集外部父级/约束/目标/极向依赖。链内先按父子顺序计算动画、层和普通约束，再执行 IK；外部子级、约束跟随者、另一独立链都等完整链求值后执行。拒绝共享节点和分组反馈环；禁用链仍校验引用。sceneEvaluator 返回矩阵、driven 集合、warnings 及 ik 残差/迭代/可达状态。渲染和对象手柄复用 driven 判断，关节辅助加入目标/极向颜色及拾取。

双段余弦定理解，固定根及世界段长；多段有界 FABRIK，确定性共线种子及极向邻点圆周投影。内外不可达取可达半径边界，达到迭代上限报告残差。世界方向旋转差乘输入线性矩阵，保留伸缩/剪切后反算局部；末端保留输入局部姿态。零长度、奇异父级和非有限结果整链保留输入。部分影响沿用 QR 混合，不能承诺非均匀父级下世界段长。

链节点全 TRS 纳入烘焙；静态 GLB 读取最终矩阵，原始动画 GLB 拒绝有效 IK 并引导烘焙。保存启用动作时禁用场景全部 IK/约束/层，保留源数据；烘焙 GLB 只改副本。局部剪切无法转换为 TRS 时拒绝。尚无关节限角、末端旋转、共享节点/闭环、参数动画和连续性优化；不能把此求解器称为完整角色绑定或专业性能达标。

## 编辑、审计与任务

0.13 的 v12 新增可选 Entity.constraints，每对象最多 32 个有稳定全局 ID 的有序约束。`constraint.put/delete/move` 管理完整参数和顺序，复制对象为约束分配新 ID 但保留目标引用；删除外部仍引用的目标拒绝。对象父级及有效目标构成依赖图，Kahn 排序确定顺序，循环错误包含环上对象名称。禁用或影响为零时不建立目标依赖；引用有效性始终检查。模型校验、原子命令、项目导入共用此规则。

`sceneEvaluator` 为每个不可变项目/场景编译顺序，每帧依次求基础 TRS、动作层、约束，返回局部/世界 Matrix4 及诊断。复制位置/完整仿射矩阵支持目标与对象独立 local/world 空间；完整复制部分影响使用自主 QR 分解，旋转 SLERP、平移/上三角缩放剪切线性混合，反射符号归 Z。朝向以实际世界轴和目标原点求旋转差并旋转输入线性部分，保留世界伸缩/剪切；支持正负跟踪轴、向上轴、世界向上向量。重合/奇异输入保留当前约束的输入并记录诊断；上方向平行时选最不平行世界基轴，随机帧访问无历史状态依赖，极点可能翻转。

SceneRenderer 对受约束节点关闭 matrixAutoUpdate，使用精确局部矩阵，普通子级/灯光/摄影机和 CPU 蒙皮随同一世界结果更新。源属性和关键帧不回写最终矩阵；对象手柄在有效约束下隐藏，组件手柄继续使用实际网格矩阵。默认向世界原点照射的旧平行光保持语义，界面可明确切换为局部 −Z 后再受朝向控制。

静态 GLB 转换最终局部矩阵，拒绝无法分解为 TRS 的剪切/退化；原始动画 GLB 对有效约束明确要求烘焙。烘焙先确定受影响通道，有效约束的所有 TRS 通道都采样，即使对象没有原始键；每个网格/探测时间只求一次全场景依赖图，包含目标动作/层边界。输出动作不保存约束元数据；启用动作时停用场景全部约束及层，数据仍在且可撤销。bakedProject 仅在副本中停用。无法表示的局部剪切拒绝，误差探测和跳变近似仍沿用已有边界规则。影响暂不可动画化，无骨骼专用空间或完整混合模式。

0.12 的 v11 新增可选 Entity.joint、Entity.skin（有序 joints、列主序 inverseBindMatrices、可选 skeletonId）和 Geometry.influences。每绑定最多 512 关节、每点最多 32 个非零影响，归一化且不重复；检查顶点数、索引、矩阵仿射性、同场景和共同祖先。绑定不是独立动作系统，节点仍经过原有 TRS/动作层/镜头时间求值；普通中间父级和隐藏关节也参与。

项目矩阵解析仅允许末行相对 `[0,0,0,1]` 有 32 倍 Number.EPSILON 内的机器余差，返回规范化副本以兼容旧本地逆矩阵结果，不批量重写库。新绑定直接规范化该行；glTF 外部输入要求精确末行。其他非仿射矩阵拒绝，避免保存后产生无效 GLB。

`skin.bind` 按对象基础姿态生成 `inverse(jointWorldRest) × meshWorldRest`，可用最近关节或首个关节初始化；共享几何先复制。`skin.weights` 按选中顶点替换并归一化，`skin.unbind` 删除绑定并显示原几何。关节被未删除网格引用时拒绝删除；网格复制保留原绑定/关节引用和重合姿态，尚不是整套角色复制。细分/合并取影响平均、挤出/UV 拆点复制、删除同步移除；合并超 32 个影响拒绝，不静默截断。

`deformGeometry` 用权重和 `jointWorld × inverseBind` 生成世界空间顶点；方向使用混合矩阵线性部分归一化。SceneRenderer 为蒙皮对象保留普通层级节点，绘制网格独立放在世界根，避免网格自身/父级变换二次作用，普通子对象仍正确继承。按关节矩阵缓存未改变的几何；当前为 CPU 变形，无 GPU 性能声明。网格编辑临时显示原几何，组件手柄使用对应节点世界矩阵；关节辅助不进入输出。对象模式下蒙皮网格不显示误导性的平移手柄，属性解释其节点语义。

glTF 导入接收 JOINTS_0…7/WEIGHTS_0…7、浮点或规范允许的量化权重、MAT4 逆绑定（缺省单位矩阵），不截断更多影响；非法编码和无效引用拒绝。多场景节点各自映射，多个图元共享源属性并分别绑定。动画输出保留源权重/绑定/关节动画，静态输出固化世界变形；绘制网格以独立根节点保存，原变换节点及普通子级保留。隐藏关节/祖先作为变换节点保留，其隐藏内容不输出。平面着色的动态蒙皮不输出固定 NORMAL，让加载端按变形后的面求法线，避免重新导入产生平滑光照差异；平滑法线仍线性变形。动作烘焙作用于关节 TRS，0.13 起也包含约束，不能代替顶点缓存。

0.11 复用 v10 的动作/轨道/关键帧，不增加项目字段或数据迁移。`action.bake` 持久化参数/actor 的命令审计，计算完成后一次添加新动作与轨道；activate 为显式选项，切换场景默认动作并禁用该场景层。原动作与层内容保留，镜头显式动作不改，事务可撤销。GUI 导出在隔离副本上仅留下该场景的烘焙动作并去掉副本的层，再复用 exportGLBWithAssets。

`bake.ts` 以 start+n×step 和区间终点为网格，补入基础动作键、层窗口/淡入淡出及源时间反算的键/循环边界。输出秒先量化 Float32；不同事件量化冲突拒绝，不能静默覆盖。可能跳变处增加两侧 Float32 样本，并以源时间运算舍入量设最小间隔（零附近的最小次正规 Float32 不足以改变 `24-frame`）。每轨最多 10000 时刻、总量 20 万键、边界分析 20 万项；step 0.01…120。无有效约束/IK 时仅为有动画的属性生成轨道，受驱动者采样完整 TRS，旋转统一单位四元数；本地父子结构保留。每段三点探测按全部/普通/边界区间记录局部位置、角度及缩放误差，不是连续时间、世界空间或图像误差上界。

GUI 分析/导出计算使用独立 Web Worker，60 秒超时或取消终止；纹理读取与 GLB 序列化沿用现有受限导出。保存新动作在服务端重算有界命令后进入原子存储，GUI 无源代码执行入口。浮点跳变只能近似，STEP 可保持每次采样值但连续运动也变为分段保持；尚无误差驱动自适应采样、键精简、世界姿态扁平化或顶点变形缓存烘焙。

v10 的可选 `animationLayers` 保存对象、同场景动作、通道、权重、模式、窗口、淡入淡出及源时间。每项目 512 层/每对象 64 层；按数组顺序叠加基础动作。窗口半开，淡入/出权重取线性包络最小值，窗口外无贡献；缺失轨道不贡献基础姿态。向量替换用线性插值，旋转 SLERP；增量向量取相对对象基础姿态的线性差（缩放也如此），四元数采用 `current × SLERP(identity, inverse(rest) × sample, w)`。不归一化不同层权重，不采用 Blender Combine 的缩放比例幂。每层复用源帧折回规则，输入帧先经过镜头映射。

`evaluatedBaseTransform` 供原动作数值/曲线/记键，`evaluatedTransform` 增加层求值。SceneRenderer/TimelineRenderer/PNG/MP4 和静态 GLB 共用后者。编辑视口的临时“预览动作层”可关闭层显示；启用时，含启用层对象的变换手柄隐藏，防止最终姿态回写到原始动作。切换取消拖动。输出始终使用完整层。层可新增/改动/删除/调整顺序，动作引用保护，删除/复制对象同步处理层；批次与撤销/快照复用原通道。原始动画 GLB 对有启用层的场景明确拒绝并引导使用烘焙；禁用层仍可导出原始动作，静态 GLB 包含完整混合姿态。

`core/gltf.ts` 独立读取有界 GLB/glTF、紧密/交错/稀疏 accessor，并将场景映射到 `scene.import` 一次事务。只读取调用者提供的字节，不访问网络或文件系统。三角列表/带/扇转换为三角索引；多图元拆成子网格，共享网格保留几何引用，多场景共享节点复制为各自实体。矩阵分解后重建核对，剪切/奇异矩阵拒绝。四元数保持原生存储；动画节点有 matrix 时拒绝。TRS 通道按各场景的节点映射复制为动作，首个相关动作默认激活；导入不修改项目时长。验证通道唯一、时间递增/min/max、输出维度与 Hermite 三倍数量；忽略无目标节点通道并列明。最多 100 源动作、每轨 10000 键、映射后合计 20 万键，另受项目 1000 动作/6000 轨道限制。

v6 Geometry 可选 normals/uv，与位置等长；法线须近似单位长度。对象变换保留属性；顶点/拓扑修改丢弃旧法线并重算，撤销恢复。UV 随删除重映射、细分插值、挤出复制、合并保留目标点值。`core/surface.ts` 共用于显示和交换，平面着色导出会拆顶点并计算面法线，浮点属性转 Float32；孤立顶点跳过，空网格保留变换节点。

`exportGLB` 对指定帧求值可见场景，保留层级，按几何/着色复用 accessor，生成静态 GLB。来源 copyright/generator 保存在 Scene.source，重导出保留 copyright。背景、环境光、阴影和生产工作流不进入 GLB，界面提示。导入平行光沿局部 −Z；旧平行光仍朝世界原点，导出时用子节点表达方向而不改变其他子对象姿态。点光源保留可选范围及线性颜色。透明仍受 Three.js 实时排序限制。

v7 Material.textures 记录基础色、金属粗糙度、法线、遮蔽、自发光的 Asset ID、UV0/UV1、边界/过滤、offset/scale/rotation。金属度 B、粗糙度 G、遮蔽 R 与材质因子相乘。图片可由 URI、Data URI、bufferView 输入，只有调用者选择的相对路径允许解析；异步计算 SHA-256。界面先实际解码并上传资源，再一次提交含 assets 的 scene.import；服务端核对已登记 blob。上传后事务失败可留下未引用文件，当前无垃圾回收。GLB 异步包装先校验可见对象原图，再内嵌 PNG/JPEG 或 EXT_texture_webp，KHR_texture_transform 保留仿射参数。

TextureBank 以内容哈希复用图片、按完整绑定/颜色空间复用纹理。加载器先校验编码、尺寸与哈希，再以无翻转/预乘/颜色转换选项创建 ImageBitmap；按贴图类别设置 GPU 颜色空间。UV 左上原点，矩阵为 offset + rotation × scale × uv。每图 8192 边长/16,777,216 像素，场景可见非空网格图片文件合计 50 MB；解码像素与 GPU 纹素各限 67,108,864。请求 15 秒超时，渲染共享 ready 屏障，失败阻止输出；换项目/场景取消旧请求，迟到位图关闭，纹理释放。编辑器显示加载/错误状态，刷新项目可重试。当前每次项目对象变化重建缓存，不宣称交互性能达标。

Geometry 增加 uv1 和 Vec4 tangents（xyz 单位向量、w 为 ±1，需有 normals）。网格形状修改清除旧法线/切线，缺切线时由 Three.js 的 UV 导数求法线贴图基底；平面着色忽略导入切线。盒式 UV 投影选择各面主轴，按局部包围盒归一化并拆接缝，复制其他顶点属性、保留三角几何，清除旧切线；命令可撤销。尚无 UV 岛编辑、绘制、烘焙或 MikkTSpace 切线生成。

动画 GLB 导出可见对象的基础姿态与全部动作；默认项目轨道形成单独动作。STEP、向量 LINEAR、四元数 SLERP、Hermite 直接保存；连续向量 linear/smooth/时间线性 Bézier 混合段可精确转换 Hermite。Euler、混合保持/连续段、混合四元数插值、非线性时间 Bézier 按整数帧及原始键时间采样为 LINEAR，并逐轨提示帧间近似。每轨最多 10000 键，Float32 时间重合或数值溢出拒绝。旧式平行光动态朝向世界原点无法直接表达，有相关动画时拒绝动画导出；项目包保留。glTF 没有当前动作选择和镜头时间轴。

当前交换不支持顶点色、形态键、正交/无限远摄影机、聚光灯、压缩与其他扩展。零缩放关键帧不满足本平台变换约束，不能用其导入可见性动画。未引用资源和 extras 的丢弃会列明，资产版权声明保留。这是基础交换，不是完整规范实现或 Khronos 认证。`gltf-validator` 和 Three.js 独立加载器仅用于开发检查，产品解析/序列化由本仓库实现。

网格编辑以实体/几何 ID、模式和索引集维护临时选择；模式转换按完整包含关系处理，位置变化保留选择，拓扑变化清空，挤出可重新选择原槽位上的顶面。选择不写项目或历史，组件索引不保证跨拓扑稳定。组件变换先把选区解析成唯一顶点集，使用列主序 4×4 局部仿射矩阵；有限值、范围和索引校验经统一事务执行。

视口使用世界空间代理手柄，中心是选中顶点平均值经完整父级矩阵变换后的点。拖动提交 `W^-1 × Pnew × Pstart^-1 × W`，将世界变换转换成局部顶点变换，因此可处理旋转、非均匀父级缩放和其组合剪切。拖动期间更新渲染缓冲预演，释放时提交一条命令；Esc、取消或上下文变化丢弃。选区切换在输入事件中同步，避免依赖下一次动画帧才刷新拾取模式。

拾取对候选点、边最近屏幕点或面进行投影，再用自主中位划分的三角包围层级检查遮挡；射线从近裁剪面开始，远裁剪外不可选，隐藏层级不参与。穿透选择忽略遮挡；框选对边中点、面中心判断。Three.js 提供矩阵、射线/三角形数学、WebGL 和 TransformControls。覆盖层/网格/手柄属于编辑器，场景清理只销毁其拥有的资源，最终 PNG/MP4 不含覆盖层。

区域挤出按选面共享顶点复制，替换顶面，仅给选区边界加侧面，清除新产生的无引用原内部顶点；不创建内部重复墙面。拒绝非流形边、选面绕序冲突、退化面、零位移和无边界选区。合并将选中顶点移到平均位置并重映射，移除重复索引面和重复三角面；删除点移除关联面，删除边移除相邻面，删除面保留顶点。空网格不删除实体。全部操作仍受 baseRevision、项目校验、撤销/版本记录保护。

动画轨道绑定对象的 position/rotation/scale（Vec3）或 quaternion（Vec4），可选 actionId。Scene.activeActionId 为空时只求值旧项目轨道，否则只求值该动作，未覆盖属性保留基础姿态。场景编辑使用此默认选择；镜头和片段可覆盖选择。此结果作为对象层混合的基础。动作只能复制同场景轨道；动作/轨道/场景引用及 Euler/四元数互斥在项目校验中约束。选择、新建、复制、改名、删除都进入事务、撤销与任务快照。

v9 的 Shot.action 与镜头 Clip.action 可为 `{actionId: ID}` 指定动作、`{actionId: null}` 指定旧项目轨道；缺省/null 表示继承。片段优先于镜头，镜头优先于场景；所有显式引用必须同场景，删除仍被显式引用的动作会拒绝整批命令。Scene.activeActionId 的旧删除清理行为保留。解析结果作为 `evaluatedTransform` / `SceneRenderer.evaluate` 的显式参数传入，不临时修改 Project，连续绘制同场景不同动作也从各对象基础姿态重新求值。

镜头 Clip.playback 缺省/null 保留旧源帧语义。非空保存 rate、rangeStart、rangeEnd、mode（hold/repeat/pingpong）。原始时间 `raw = sourceIn + (timelineFrame - start) × rate`；rate 为 −16…16，0 定格，sourceIn 可为有符号小数。hold 钳制到闭范围；repeat 以范围长度取模，正放包含起点、排除终点，倒放相反；pingpong 以两倍范围长度取模后折返。周期端点以有界浮点容差归并，不能保证极大相位/极短周期下的无限精度。源范围限 0…100 万帧、跨度至少 1e-6，整个片段原始时间限 ±10 亿帧。媒体仍仅允许 0…100 万非负整帧入点，不接受动作或动画变速。

`clip.split` 按原始时间设置后段 sourceIn，不能先折返，否则丢失往返方向和循环相位。动作选择、速度、范围和模式原样保留。移动起点保持入点，修改时长只裁剪/延长播放窗口，修改速度/范围不自动调整时长。“采用动作范围”显式读取选中动作最早/最晚键，固定保存范围并重置入点；之后改键不会自动改该范围。没有关键帧时默认 0…1，单键或极窄范围扩为有效窗口。TimelineRenderer 对摄影机和全部场景对象使用同一动作/源帧；场景编辑不追随片段调度。成片调度只保存在项目包，glTF 仍为场景动作交换。

关键帧保存非负有限帧数、后续段插值和可选手柄/切线；手柄是相对 `[Δframe, Δvalue]`，左右时间偏移分别非正/非负。Bézier 段先反求时间三次式，再计算值三次式；跨越的时间手柄同比缩短以维持单值映射，原始手柄不改写。首尾范围外保持端点。Hermite 保存每帧入/出导数，求值乘实际键间距；切换至 Hermite 时补零切线。四元数 LINEAR 取最短弧 SLERP，Hermite 逐分量后归一化，不擅自翻转三次键的符号。零键拒绝；三次分量通过导数极值隔离根，再检查共同零点，长度低于 1e-8 的退化候选拒绝保存；取样仍保留非有限/零长度防护。曲线适配和绘制用 48 分段近似显示 Hermite/SLERP，不是精确极值包围。

自由手柄独立；对齐手柄反向共线，拖动时保持另一侧长度；向量手柄朝邻键并取三分之一间距；自动限幅使用相邻割线的加权调和切线，极值处为零，末端为单边割线。它是本项目的局部算法，未复现 Blender 连续加速度求解。每轴左右共用类型；手动移动自动/向量手柄会转为自由。

`key.update` 按 ID 改时间/值/插值，撞帧拒绝整批命令；`key.handle` / `key.handles` 编辑单轴手柄/类型。兼容的 `key.set` 按帧插入或更新，未指定插值时保留已有插值/手柄，新键默认线性。图形编辑器仅克隆当前轨道做拖动预演，松开后一次提交；Esc/pointercancel 丢弃，项目修订变化会取消未提交拖动。后台仍以 baseRevision 拒绝并发覆盖。三维属性、时间轴选择、曲线、逐帧渲染共用此模型。

`POST /api/projects/:id/commands` 接收 `{baseRevision, actor, label, commands}`。服务检查来源，复制项目，应用整批命令并验证引用，然后在同一 SQLite 事务写入快照、撤销状态及审计。错误不写项目；版本冲突返回 409，客户端提示刷新，不自动覆盖。

撤销重做恢复快照，但修订号递增。恢复历史也是一次可撤销操作。actor 是本地声明的 user/agent 标签，不是经过认证的身份；后台产物登记用 system。没有任意 JS、shell 或用户插件执行入口。

任务固定快照并存 requestKey。逐帧黑底，按视觉轨道低到高合成镜头或媒体。FFmpeg 根据同一入点、开始帧和时长裁剪/延迟/混音，使用参数数组调用，不构建 shell 字符串。视频和独立音频使用第一条音轨；导出重新探测真实文件，兼容没有音轨元数据的旧素材，无音轨视频仍可导出。

音频在 48 kHz 下按边界取整，处理音轨相对容器的开始偏移，以采样数执行 atrim/adelay；用 `asetpts=N/SR/TB` 重建时间戳，避免无效输入时间戳传播。单声道以单位增益复制到立体声；片段增益 0–2，混音关闭隐式归一化。浏览器用 MediaElementAudioSourceNode → GainNode → 共享输出，保持相同增益范围。预览会按时间轴纠偏，但不是采样精度调度；环绕声、多音轨选择和限幅尚未实现。编码后核对视频尺寸/时长及音轨时长/起点，异常结果不会标记成功。

完成后保存实际字节数及 SHA-256，把 MP4 纳入素材。`registerResult` 在同一数据库事务中登记 blob、追加 Asset/Artifact 系统修订并完成任务；失败回滚，重复完成不重复登记。文件先写入内容寻址目录，事务失败可留下未引用 blob。当前编辑器需刷新同步，没有实时订阅。

## 外部生成状态

Seedance 仅请求固定的官方北京 API 地址，API Key 只在服务端。模型 ID 不硬编码；用户选择与之对应的系列，应用按公开文档验证基础参数。首尾帧使用库中 PNG/JPEG/WebP 的 Base64，检查内容哈希、尺寸和每张 20 MB 限制；签名产物 URL 不写项目或日志。

新建任务先持久化 submitting，再发 POST，取得 taskId 后先保存再轮询。已有 ID 的重启任务恢复 GET；没有 ID 且可能已经提交的任务标为 uncertain/interrupted，需要用户核对并关联，禁止直接重试生成。查询/下载错误保留已有 ID；每轮本地最多等待 60 分钟，随后可恢复。外部状态没有百分比时界面显示不定进度。

取消先读取远端状态，只对 queued 调用 DELETE，再查询确认；running 不支持取消，不伪称已停止。官方 DELETE 在已完成状态会删除记录，因此排队到完成之间仍有供应商端竞态，本地不会把 DELETE 成功响应直接标成 cancelled。未知结果保留为 interrupted 供核对。

成功结果从允许的 `.volces.com` HTTPS 地址流式下载，重定向逐次复核；不携带 API Key，最大 50 MB、120 秒，随后 ffprobe 探测真实视频。生产没有模拟提供者或自定义代理 URL。测试使用注入的协议夹具，实际供应商端行为、网络恢复和权限仍待有凭据的集成运行确认。

只监听本机并检查变更来源，不是远程多租户安全方案。JSON 全量快照和包会占用内存，大型项目需增量事务及流式存储。媒体解码依赖浏览器/FFmpeg。H.264/AAC 及 FFmpeg 发行许可、专利需针对发行方案评估，相同效果不代表没有权利限制。
