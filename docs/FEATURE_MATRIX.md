# 功能覆盖矩阵

基线：2026-10-23，版本 0.11。最终范围仍是 Blender 与 LibTV 的完整制作能力，不限于当前基础编辑器。以下未实现项是保留的范围，不是删除的需求。后续研究发现更多单元时继续扩展本表。

深度定义：**基础支持**=有可执行实现和局部运行依据；**专业可用**=工作流与边界足以承载专业任务；**性能达标**=在明确数据规模/硬件指标下实测达标；**功能完整**=指定范围全部实现并验证。当前没有单元获评后三个等级。数据类型的存在、按钮和节点不计作相应功能已完成。

## 依赖已满足的下一项

1. 0.11 对象层结果的有界采样、新动作保存和 GLB 烘焙已进入统一流程，原数据保留，误差/边界限制明确。下一单元是骨架与蒙皮公共基础：关节层级、逆绑定矩阵、顶点权重、统一变形求值和 glTF 蒙皮交换；复用现有动作和层。烘焙误差控制/键精简、UV 岛、环境照明和完整材质范围继续保留。
2. 多边形拓扑、稳定组件身份与节点产物执行协议按依赖继续推进。Seedance 适配器已编码，真实调用仍待授权配置；当前继续其他可完成能力。
3. 视频原声、统一增益和画幅适配已进入 0.2；后续扩展波形、音轨选择、预览调度和拖拽剪辑。

这是随证据调整的工作队列，不是缩减目标或固定阶段方案。仍须研究和实现全部未实现专业单元。
