# 功能覆盖矩阵

基线：2026-10-22，版本 0.5。最终范围仍是 Blender 与 LibTV 的完整制作能力，不限于当前基础编辑器。以下未实现项是保留的范围，不是删除的需求。后续研究发现更多单元时继续扩展本表。

深度定义：**基础支持**=有可执行实现和局部运行依据；**专业可用**=工作流与边界足以承载专业任务；**性能达标**=在明确数据规模/硬件指标下实测达标；**功能完整**=指定范围全部实现并验证。当前没有单元获评后三个等级。数据类型的存在、按钮和节点不计作相应功能已完成。

证据索引：R1/R2/R3 见 [研究记录](research/2026-10-21-foundations.md)；C=`tests/core.test.ts`；I=`scripts/smoke.ts` 与实际产物；S=本仓库实现可检查但未全面验证。U=目标范围中已列入，尚待独立单元研究。

M=[媒体研究与实际运行](research/2026-10-22-media.md)、`tests/media.test.ts`、`scripts/media-smoke.ts` 及 `examples/media-edit.*`。

G=[供应商接口与状态研究](research/2026-10-22-seedance.md)、`tests/generation.test.ts` 和 `scripts/workflow-smoke.ts`。G 的协议夹具不能证明真实供应商生成成功。

A=[动画曲线规格与运行](research/2026-10-22-animation.md)、`tests/animation.test.ts`、`scripts/animation-smoke.ts` 和 `examples/animation-curves.*`。

## 依赖已满足的下一项

1. glTF 2.0 场景交换：复用几何、层级、材质与动画，研究坐标和插值语义，完成有边界且真实可用的导入/导出；这是下一单元。
2. 多边形拓扑、稳定组件身份与节点产物执行协议按依赖继续推进。Seedance 适配器已编码，真实调用仍待授权配置；当前继续其他可完成能力。
3. 视频原声、统一增益和画幅适配已进入 0.2；后续扩展波形、音轨选择、预览调度和拖拽剪辑。

这是随证据调整的工作队列，不是缩减目标或固定阶段方案。仍须研究和实现全部未实现专业单元。
