## 环境注意

Windows PowerShell 禁用了 npm.ps1，使用 npm.cmd。受限运行环境会使 tsx 的 `os.userInfo()` 报 `uv_os_get_passwd ENOMEM`，并可能阻止 esbuild 读取父目录；已通过工具的正式权限提升运行开发、构建和检查，不通过绕过沙箱处理。真实系统内存约 31.5 GB，CPU 16 逻辑线程；该错误不代表已验证内存耗尽。
