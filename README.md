# Frameforge Studio

独立开发的三维、动画、影视剪辑与 AI 工作流平台。当前为 **0.23 基础版本**，完整目标仍是覆盖 Blender 与 LibTV 的功能范围；尚未达到专业可用、性能达标或功能完整。

已有真实能力：统一项目格式、SQLite 自动保存、跨重启撤销重做、版本审计、结构化 Agent 命令、三维对象/层级/材质编辑、顶点移动/三角面挤出/线性细分、OBJ 导入导出、变换关键帧、镜头与媒体时间轴、便携项目包、本地工作流与带音频 MP4 后台导出。Seedance 正式接口适配器、参数编辑及任务恢复已编码并通过本地协议/集成检查；当前缺少凭据，尚未验证真实供应商生成，不返回模拟生成结果。

## 启动

环境：Node.js **24.15 或以上的 24.x**、npm、Chrome/Chromium/Edge、FFmpeg 与 ffprobe。Windows 已实际运行 Node 24.20.0、Chrome 155.0.8059.82、FFmpeg 9.0.2。浏览器与 FFmpeg 由用户安装。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 **http://127.0.0.1:4173**。macOS/Linux 使用 `npm`，并按需设置 `STUDIO_BROWSER_PATH`；目前运行证据来自 Windows。

```powershell
npm.cmd run build
npm.cmd start
```

第二组使用构建产物运行。当前服务仍依赖 tsx 与 Vite 包，安装时保留开发依赖，不使用 `--omit=dev`。后端修改后需重启服务；前端由 Vite 更新。

配置见 [.env.example](.env.example)。服务读取进程环境变量，不自动读取 `.env`；PowerShell 可用 `$env:PORT='4173'`。默认数据目录 `.local/data` 包括 `studio.sqlite`、素材 `blobs/` 和任务 `renders/`。备份时先停止服务，再完整复制此目录。不要删除 `.local` 来重新安装。

0.23 使用项目格式 v18，新增保持当前世界姿态的重设父级命令与可保存仿射补偿；原动画键和绑定保持可编辑。保留多键时间编辑、自适应烘焙、精简、骨架重定向与 FK/IK 匹配。格式包含独立基础姿态与固定动画参考，保留 IK 影响/极向角的单值动画轨道，保留限角、关节、蒙皮、动作层/烘焙、镜头调度、四元数、图片材质、UV、网格和媒体数据。首次读取旧数据库时，先在 `backups/` 保存完整 SQLite 副本，再原子升级当前项目、撤销历史、版本及任务快照，并记录迁移。支持导入 v1–v17 包：保留原动画、关键帧 ID、音量、画幅及生成设置，v1 继续使用原有拉伸；不改原文件，未知格式拒绝导入。旧绑定矩阵末行仅规范化机器精度范围内的舍入余差。

## 使用

1. 新建项目，添加网格、摄影机或灯光。选中对象后编辑属性或使用视口手柄。`G/R/S` 切换变换，`Delete` 删除选中对象或片段。
2. 在帧 0 记录变换关键帧，移动播放头再改变属性。已有动画属性会更新当前帧关键帧并保留插值和手柄。在“动画曲线”选择属性及 XYZ 轴，编辑时间、值、保持/线性/smoothstep/Bézier 插值和自由/对齐/向量/自动限幅手柄。空白处拖动框选，Shift 增减选择，时间轴与曲线共享多选。单键拖动改时间和值，多键只改时间，松开保存、Esc 取消，中键平移。“适配曲线”找回移出视野的键。曲线工作区 Delete 删除全部所选键，可整组撤销。
3. 镜头引用摄影机和场景，可选择默认动作；片段可继续覆盖动作。选中镜头片段，在“镜头动画”开启自定义播放，设置速度、源范围、保持/循环/往返；负速度倒放，0 定格。“从末尾倒放”同时设置入点与速度。“将当前视角用于镜头”保存摄影机姿态。“成片预览”显示调度后的时间轴输出，自由编辑视角与网格不进入成片。
4. 导入图片、视频或音频后加入时间轴。在片段属性中移动、调整入点/时长/轨道，`K` 在播放头处切分。图片与视频支持完整显示、居中裁切铺满和拉伸；新片段默认完整显示。视频原声随片段入点、切分、静音和音量一起编辑；预览与导出均支持 0–2 倍增益。同轨片段不能重叠；视觉高轨覆盖低轨，未覆盖区域显示低轨，音轨混合。
5. 每次有效命令自动保存。`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做，关闭重开后仍保留。版本记录可审阅命令、恢复旧快照；Agent 命令先预览校验，再应用。
6. “导出 MP4”或运行本地工作流会提交真实任务。任务固定提交时的快照，继续编辑不影响正在导出的内容。结果可下载并登记为素材；点击“任务 → 同步导出素材”更新当前编辑器版本。
7. 保存项目包会下载含素材的 `.ffstudio` 文件；“打开”校验并导入，ID 冲突时创建副本。产物素材随包携带；完整历史与运行任务留在本机数据库。

可打开的项目与实际导出结果见 [examples](examples/README.md)。

对象属性的“父对象”默认保持当前场景帧的世界姿态，用完整仿射补偿保留原频道、关键帧和蒙皮绑定。可脱离到场景根节点，也可取消勾选以保留局部变换。当前帧以外继承新父级运动，不承诺整段动画不变；局部约束、IK 或非法骨架层级若影响最终姿态，会拒绝整次修改。带补偿的普通对象仍可用世界轴手柄编辑，无法由原频道表示的剪切操作会报错。“使用层级补偿”开关保留矩阵以便恢复；关闭会改变姿态。项目包和 PNG/MP4 保留仿射结果，含剪切的静态 GLB/动画 TRS 烘焙仍明确拒绝。详见 [层级编辑依据](docs/research/2026-10-26-parenting.md)。

场景结构旁的 **glTF** 可导入 `.glb`，或同时选择同目录 `.gltf`、`.bin` 和图片。资源在子目录时选择整个文件夹，其中只能有一个 glTF/GLB。先显示数量和转换说明，再一次保存到当前项目，支持撤销。覆盖层级、共享三角网格、法线/切线、UV0/UV1、五类 PBR 图片贴图、透明/自发光、有限远透视摄影机、点光源/平行光、TRS 动作及线性混合蒙皮。顶点色、形态键、聚光灯或未支持扩展仍会拒绝导入并说明原因。完整交换范围仍待实现。

场景下方的“动画动作”可选择、新建、复制、改名和删除动作。基础动作选择优先级为片段 → 镜头 → 场景默认，也可显式选用原来的“项目动画”。被镜头、片段或对象动作层显式引用的动作不能删除，先移除引用或选择其他动作。导入的秒时间按项目帧率换算，保留小数帧；项目时长不会自动延长。四元数曲线显示 XYZW，编辑后归一化，线性段使用球面插值；Hermite 切线以分量/帧编辑。Alt 拖动关键帧保留连续时间，普通拖动按整帧增量移动。媒体和镜头片段仍按整帧插入、切分。

选中对象，在属性的“对象动作层”添加同场景动作，设置权重、通道、起点/时长、淡入淡出和源时间。列表从上往下混合到基础动作，后面的层后生效；窗口外无影响，没写键的通道保持之前结果。替换层用权重插值，可让上层动作保持全权重、后层淡入形成过渡；多个层的权重不自动归一化。增量层的位置与缩放取相对原动画频道基础值的线性差值，旋转叠加局部四元数差值，缩放不是比例相乘；独立基础姿态偏移在混合之后应用。支持禁用、调整顺序、删除和撤销。摄影机同样支持对象层。

属性变换与曲线编辑的是场景动作原值。编辑源动作时关闭三维视口的“预览动作层”，再选择场景动画动作；启用层预览时，该对象的空间手柄隐藏，以避免将混合姿态写回原动作。此开关只影响编辑视口，成片预览、PNG/MP4 和当前帧 GLB 始终包含已启用的层。每层使用镜头映射后的场景时间，再独立映射到其源动作时间。

镜头片段的源入点允许小数或负数，循环时表示尚未折回的源时间；切分保留相位和往返方向。速度和播放范围改变时，片段位置/时长不自动改变；循环次数由时长、速度和范围共同决定。“采用动作范围”读取当前动作的最早/最晚关键帧并重设入点。预览/PNG/MP4 共用此映射；场景编辑与曲线编辑仍使用场景默认动作和源帧。摄影机、灯光及对象先按片段时间求值；对象层可继续独立映射源动作时间。媒体的源入点仍必须为非负整帧，尚未加入媒体变速。

“导出当前帧 GLB”保存当前可见场景的静态混合姿态；“导出动画 GLB”保存本场景可见对象的全部原始动作与基础姿态，两者均内嵌原始图片。存在启用的层级补偿、基础姿态偏移、对象动作层或有效约束/IK 时，原始动画 GLB 提示改用“烘焙动画 GLB”；禁用所有这些来源后可导出原始频道动作，视觉结果可能改变。STEP、线性/SLERP 和兼容 Hermite 段保留原生插值；Euler、混合保持段、非线性时间 Bézier 等按项目帧率及原始键时间采样，帧间结果可能有差异并显示说明。完整曲线、基础姿态、层、约束、IK、当前动作选择、镜头时间轴、背景和工作流请保存项目包。

glTF 窗口的“烘焙混合动画”可指定基础动作、场景帧区间、步长、线性/保持插值及起点归零，计算包含启用层级补偿、对象层、基础姿态偏移、约束和 IK 的结果。采样补入全场景的键、窗口和循环边界，并报告普通区间与边界区间的探测误差；这些不是全区间上界，跳变仍有量化/过渡近似。计算可取消，每轨最多 10000 时刻、合计 20 万键。导出不改项目；“保存为新动作”保留源动作、层、约束和 IK。勾选“启用烘焙动作”会切换场景默认动作并停用本场景所有层级补偿、层、基础姿态偏移、约束及 IK，整批可撤销；镜头/片段的显式动作选择需自行调整。烘焙关节动作时保留绑定和权重，仍不是顶点缓存或镜头时间轴烘焙。局部剪切/退化矩阵不能保真保存为 TRS 时明确报错。

在对象属性的“变换约束”中添加目标朝向、复制位置或复制完整变换，选择目标、影响值及顺序。复制支持独立选择目标/对象的世界或相对父级空间；朝向可选择有符号局部轴、向上轴和世界向上向量。约束在基础动画/动作层之后从上往下求值，摄影机与关节共用；平行光需启用“方向跟随对象 −Z”。隐藏目标仍参与求值。循环依赖拒绝整批修改，被引用目标不能直接删除。

约束启用时对象手柄隐藏，属性与记键仍编辑源变换；可暂时禁用约束再使用手柄。重合目标或不可逆父级会保留该约束的输入姿态，并在编辑视口显示诊断。朝向越过极点可能翻转；影响暂不能记键。完整复制保留仿射剪切，视口、蒙皮和影片共用结果；静态/烘焙 GLB 无法表达局部剪切时拒绝导出，项目包仍保留可编辑数据。

选择具有至少两段父子链的根对象，展开“IK 链控制”，选择末端并“创建 IK 链与控制器”。在场景结构选择橙色目标或紫色极向对象，移动/记键即可控制整条链；“显示关节”控制这些编辑辅助点。链在普通动画/约束之后求解，跟随对象、摄影机和蒙皮读取求解结果。面板可改目标、极向、极向角、影响、容差和迭代上限；支持禁用、移除、撤销与保存。

双段使用几何解，多段使用有界 FABRIK；根位置和全影响时的世界段长固定，不自动拉伸。目标不可达或迭代未收敛会显示残差，零长度/奇异父级保留输入并诊断。链长 2…32 段，最多 128 条，可被动画激活的启用链暂不能共享节点。尚无末端旋转；目标/极向的普通动画可用。正影响的受驱动关节手柄隐藏，属性仍编辑输入动作；零影响 FK 在没有基础偏移、约束或层覆盖时可使用手柄。非均匀缩放可能产生局部剪切，部分影响不保证世界段长；GLB 需烘焙且不能保存剪切。

在“IK 参数动画”选择影响或极向角，记录当前帧后编辑键时间、数值、插值、Bézier 手柄或 Hermite 切线。曲线属于当前场景动作，支持动作复制、镜头/片段覆盖和撤销恢复。根关节的对象动作层勾选“IK 控制”后可混合这些参数；增量参照链保存的基础参数。影响在所有层混合后限制到 0…1，极向角连续插值，允许多圈。上方静态参数是无对应轨道时的基础值。可激活链始终加入依赖检查，即使当前影响为零；禁用 IK 才退出求解。硬限角在正影响时生效，零点和求解分支可能跳变；单独改变参数不会自动 FK/IK 对齐，可使用“FK / IK 姿态匹配”。烘焙保留最终运动，完整参数编辑需保存项目包。

在“IK 链控制 → FK / IK 姿态匹配”选择新键的保持/线性插值，再点“匹配到 FK 并记键”或“匹配到 IK 并记键”。匹配使用当前场景源帧、场景动作和完整动作层；当前可见关节姿态通过完整矩阵检查后一次保存。FK 记录关节输入和零影响；IK 同时记录关节输入以保留扭转，把目标/极向放到匹配位置，并记录全影响和零极向角。原基础姿态、绑定、权重及层不改，整批可撤销。

同帧已有键保留 ID、插值与手柄，新键写入当前动作。匹配只核对当前帧，新增键可能改变相邻区间及首尾保持；不是整段动作重定向或范围烘焙。可逆层会反算，全权重覆盖、普通约束、限角、剪切或单极向无法表达的多段曲率可能无法匹配，失败时不保存任何修改。匹配不使用视口“预览动作层”开关，因此编辑源曲线前应确认当前动作和完整姿态。

在“IK 链控制 → 关节限角”选择非末端关节，添加单轴铰链或摆动锥/扭转限制；上下限相等可锁定角度。轴在记录的参考姿态内定义，角度区间不能跨越 ±180°。添加与“重新记录输入姿态为零”使用当前帧、排除本链 IK 的动画/层/普通约束结果，不改变蒙皮绑定。可修改参考轴、上下限及锥半角，显示实际角度，支持停用、删除和撤销。

受限链使用投影坐标下降，每个候选和部分影响混合后执行硬限角；影响大于零时，即使输入越界也会被限制，影响为零/停用 IK 时恢复输入。保持局部位置及伸缩，非均匀父级下世界段长可能改变。极向是初始偏好，限角优先；停止改善或达到迭代上限会显示残差，不能据此断言目标不可达。随机帧确定，但不保证全局最优或运动连续；GLB 仍需采样烘焙。

“添加对象 → 关节”创建可编辑关节，在属性中设置父对象、变换和关键帧。选择网格，展开“骨架与蒙皮”，选择具有公共根的关节并“以基础姿态绑定”；最近关节初始化只是起始权重，也可全部赋给首个关节。绑定可撤销，重新绑定会替换权重；共享几何先复制。网格的变形由关节驱动，网格节点自身变换只影响普通子对象；移动整套角色应调整关节共同父级。

三维编辑工具栏的“基础姿态”显示不含动画、动作层、约束和 IK 的骨架基础。选择关节、骨架成员或祖先，用专用字段/手柄修改；默认“保持蒙皮基础外形”会补偿所有受影响的逆绑定矩阵，保持这个基础视图中的网格世界外形，权重和几何不变。关闭此项则保留绑定，让网格随基础变化。已有频道与关键帧保持原值，相对固定参考在新基础上运动；不保证整段动画外形不变。新建绑定也使用这个独立基础视图。

“复制当前帧局部姿态到基础”复制正常动画求值的局部变换，可包含骨架子节点；不会清除原动画、重算限角参考或固化网格，重新播放时原运动偏移仍会叠加。有求解诊断或无法表示为 TRS 的局部剪切时拒绝。重置可移除基础偏移并选择补偿。退出基础模式查看运动结果；PNG、GLB 和 MP4 始终输出正常动画。含基础偏移对象的普通姿态手柄隐藏，数值/曲线仍编辑原频道；基础模式手柄可用。

进入“编辑网格”显示原始几何，选择点/边/面后可读取首个顶点权重、增加或移除关节影响，再应用并归一化到全部选中顶点。细分/合并平均权重，挤出/UV 拆点复制，删除同步移除；最多每顶点 32 个影响、每绑定 512 个关节，超限拒绝。视口“显示关节”仅是编辑辅助；成片、PNG 和后台输出共用实际变形。动画 GLB 保存绑定与关节动画，当前帧 GLB 固化当前姿态；解绑恢复原始几何，不固化变形。没有完整约束体系、保持体积、权重绘制或自动热扩散权重。

在网格属性的“材质贴图”中选择素材库图片，编辑基础色、金属粗糙度、法线、遮蔽、自发光贴图及其 UV 通道、边界、过滤、偏移、缩放和旋转。无 UV 的网格先用“生成/覆盖 UV0/UV1”；盒式投影会拆分接缝顶点，覆盖所选通道，形状不变且可撤销。图片仍在同一素材库，被材质引用时不能删除。基础色/自发光使用 sRGB，金属粗糙度使用 B/G 通道，遮蔽使用 R 通道；参数与图片采样值相乘。

网格修改会重算法线并移除旧切线，使用 UV 导数求法线贴图基底，撤销可恢复原始属性。UV0/UV1 随顶点保留、细分插值、挤出复制、合并保留目标点 UV，尚无 UV 岛编辑、绘制或烘焙。原有项目继续使用平面双面材质；混合透明采用实时排序，自发光不照亮其他对象。图片加载完成前不输出缺贴图画面；加载失败会显示错误并使导出任务失败。

选中网格对象后点击“编辑网格”，使用点/边/面模式（1/2/3）点击选择，Shift 单击切换选中状态；B 切换框选，Shift 添加、Ctrl 移除。普通选择只选可见组件，“穿透选择”可选择背面。G/R/S 手柄以选中顶点的平均位置为中心、使用世界轴；右侧数值使用局部坐标。一次拖动只保存一次，Esc 取消。右侧还可进行区域挤出、合并和删除；Delete 删除组件，删空后仍保留对象。几何编辑影响全部动画帧，不生成形状关键帧。

## 骨架动作重定向

左侧“重定向”打开映射编辑器。选择源根、目标根并逐行指定对应节点；支持不同场景、名称、骨长、基础轴向及额外父节点。未映射目标节点保持基础局部姿态。根到根必须映射，源与目标子树不能重叠；唯一同名填写由用户明确触发。保存映射后可随项目包重开、修改或删除。

选择源基础动作、范围、步长、插值和是否归零；配置根位移开关/比例、XYZ 方向对齐。源采样包含启用的动作层、约束和 IK。参考使用已存基础姿态（即使其动画偏移被停用），无记录时使用对象变换；因此启用结果后仍可复用映射。计算误差在可取消 worker 中运行，显示平滑段与跳变邻域的四分点局部误差。

“生成重定向动作”把整个目标根子树写成新动作，保留原动作、参考和蒙皮数据。默认启用会切换目标场景默认动作并停用该子树的基础偏移、层、约束和完整 IK 链；部分跨界 IK 链拒绝启用。场景内其他对象受默认动作切换影响，镜头/片段指定的动作仍优先。只保存不启用时，需先停用这些驱动再使用结果，避免重复变换。整次操作可撤销。

这是基础方向变化与根位移转移；不转移非根平移/伸缩，不做人体识别、脚底锁定、手部接触或扭转骨分配，也不保证目标限角。采样不是连续时间误差保证；最多 10000 样本/轨、20 万输出键及约 200 万次节点采样预算。GLB 保存生成动作，完整映射请保存项目包。实际可打开 [重定向作品](examples/retargeted-performance.ffstudio)、[影片](examples/retargeted-performance.mp4)，运行依据见 [研究与边界](docs/research/2026-10-25-retarget.md)。

## 自适应动画烘焙

在 glTF 面板的“烘焙混合动画”启用“按探测误差自适应补样”。步长作为初始最大间隔，设置位置/缩放分量容差、旋转角容差和最小采样间隔；每个区间检查五个内部时刻，根据最终层/约束/IK 的局部变换差异继续补样。原始键、层边界和跳变邻域继续保留。

分析可取消，并显示初始/最终采样数、输出键数、探测差异与未达标原因。最小间隔、时间精度、键数/深度或采样预算阻止继续补样时，结果可分析但不能保存或导出。有限探测可能漏掉短暂或高频变化，跳变保护段单独报告，不承诺连续时间或世界空间误差。每轨 10000 时刻、合计 20 万键、深度 20、约 200 万节点采样；固定模式也受节点工作上限约束。

保存和直接 GLB 输出使用同一判定，源曲线和驱动数据保留。勾选启用时仍按完整场景烘焙语义停用重复驱动；镜头/片段覆盖需自行调整。重定向当前仍使用固定步长。可打开 [项目](examples/adaptive-performance.ffstudio)、[动画 GLB](examples/adaptive-performance.glb)、[影片](examples/adaptive-performance.mp4)，详见 [研究与运行记录](docs/research/2026-10-25-adaptive.md)。

## 动作关键帧精简

选择场景与源动作，点击左侧“精简动作”。设置范围以及位置（米）、旋转/极向角（度）、缩放和 IK 影响容差；0 表示该类通道不删键。分析可取消，不写入项目；“保存精简新动作”复制完整动作，只在范围内精简，保留源动作、区间外曲线与保护边界，整次操作可撤销。默认启用仅切换场景动作，基础偏移、层、约束和 IK 继续生效，镜头/片段覆盖仍优先。

支持保持、线性、smoothstep、Bézier、Hermite 和四元数曲线。数值曲线使用控制点差上界，四元数按区间界限细分；无法确认或达到预算的区间保留原键，不能保证键数最少。容差约束原始局部通道，不保证世界空间、接触、蒙皮或图像误差；要处理最终姿态可先烘焙或重定向。输入限 20 万键、100 万次检查；分析 60 秒超时。

实际作品 2377→154 键，原动作仍可编辑：[项目](examples/reduced-performance.ffstudio)、[原生动画 GLB](examples/reduced-performance.glb)、[影片](examples/reduced-performance.mp4)。原生 GLB 保留精简 clip；重新烘焙可能再次增加键数。研究、运行记录与限制见 [精简单元](docs/research/2026-10-25-reduce.md)。

## 多键时间编辑

在“动画曲线”框选或选择当前曲线/对象全部键，A 全选当前曲线、Alt+A 清空；也可 Shift 点击时间轴上的不同变换轨。多键拖动按整帧增量移动，Alt 拖动保留子帧。每次拖动只提交一个修订，Esc 或项目修订变化取消未提交的预演。

批量面板使用“枢轴 +（原帧 − 枢轴）× 正倍率 + 偏移”。枢轴可为首帧、范围中心、播放头或指定帧。“复制所选键”使用同一时间变换并选中新副本；“删除所选键”可整组撤销。撞帧、越界、时间精度塌缩或非法曲线都拒绝整组，不覆盖原键。单键属性区明确只编辑活动键。

时间缩放同时改变 Bézier 手柄时间跨度与 Hermite 每帧切线，保持仍相邻的已选键之间的曲线。自动/向量手柄固定为自由手柄；与未选键或新插入键相连的段可能改变。时间轴长度、动作层窗口与镜头调度保持原设置。图形多选目前覆盖同一对象当前动作的 TRS/四元数；IK 单值支持相同批量命令，专用面板仍为单键编辑。负倍率反转、跨对象选键和跨动作粘贴尚未实现。

真实作品：[项目包](examples/key-editing.ffstudio)、[动画 GLB](examples/key-editing.glb)、[三秒影片](examples/key-editing.mp4)。研究和边界见 [多键编辑记录](docs/research/2026-10-25-key-editing.md)。

## Seedance 工作流

在工作流中添加“文本输入”和“Seedance”并连接；生成设置保存模型 ID、对应系列、时长、分辨率、画幅、随机种子、原声和水印，以及可选的素材库首尾帧图片。点击节点上的生成按钮执行该输出；多个输出互不强制执行。结果下载、探测并登记到同一项目素材库后，可加入时间轴继续剪辑。

服务端从 `ARK_API_KEY` 读取密钥，`STUDIO_SEEDANCE_MODEL` 可提供默认模型 ID。付费生成默认关闭；确认供应商权限和预算后，由运行者在启动环境设置 `STUDIO_ENABLE_PAID_GENERATION=true`。本平台尚无金额预算控制或价格估算。配置改变后重启服务；密钥不放进项目、浏览器或日志。当前开发运行没有配置密钥或调用付费生成。

已有供应商任务 ID 的中断任务使用“恢复查询”，不重新生成；提交响应丢失时需在供应商控制台核对此次任务 ID 后关联。只有远端排队状态可请求取消，最终状态以供应商查询结果为准。失败/已取消任务的“重新生成”会创建新计费任务。详细依据和限制见 [供应商研究记录](docs/research/2026-10-22-seedance.md)。

## 当前边界

- 本地单用户、loopback 监听；无远程鉴权、协作编辑或生产部署。
- Three.js 提供 WebGL 基础组件；几何算法、项目格式、命令、求值和任务由本仓库实现，不调用 Blender / bpy。
- 只有基础三角网格建模及线性骨架蒙皮，无雕刻、UV 岛编辑、完整角色绑定、物理、节点材质、路径追踪、合成器、跟踪等。CPU 蒙皮尚无大规模性能达标证据；扭转可能损失体积，平滑法线使用线性混合方向。OBJ 仅保存原始网格位置、面及凸多边形扇形三角化，不保存蒙皮、UV、法线、MTL 或层级。glTF 所选文件合计 50 MB、JSON 20 MB、单网格 10 万顶点/20 万三角面、导入合计 30 万顶点，最多 2000 对象；不支持远程 URI 和压缩扩展。
- 贴图支持静态 PNG/JPEG/WebP、UV0/UV1、基础 PBR、KHR_texture_transform 与 EXT_texture_webp。每张不超过 8192 边长及 16,777,216 像素，并受实际 GPU 尺寸限制；当前场景可见网格的图片文件合计不超过 50 MB，解码像素和 GPU 纹素分别限制为 67,108,864。没有 UDIM、压缩纹理、视频纹理、ICC/EXIF 定向色彩流程或完整 glTF 材质扩展支持。
- 网格的边由三角面推导，包括面内对角线；暂不支持独立线段、四边面/n-gon、环选、比例编辑、吸附或多对象编辑。框选按点/边中点/面中心判断。组件选择是临时索引，拓扑变化后清空；区域挤出保留顶面选择。区域挤出采用指定局部位移，拒绝无边界的整体封闭选区、非流形边和退化面，尚无自动法线方向或自交修复。
- 动画支持分数帧、XYZ/XYZW 成组时间/插值、Euler 或四元数；同一动作不能在同一对象上并存两种旋转轨道。自动限幅为自主局部单调算法，不等同 Blender 的平滑求解器。动作只在同场景复制；镜头级调度和对象有序层混合已接入；每项目最多 512 层、每对象 64 层，权重不归一化，缩放增量为线性差值。已有基础层动画采样烘焙；尚无完整 NLA、权重曲线、连续时间采样误差证明、自动链拟合/接触修正、跨对象图形选键、曲线循环外推或旋转解缠。片段速度限 −16 至 16，源范围在 0–100 万帧内；仅恒定速度，无速度曲线、时间抗混叠或运动模糊。导入最多 100 个源动作、单轨 10000 键、映射后合计 20 万键；采样导出也限单轨 10000 键。四元数零长度曲线拒绝保存；缩放曲线仍可能在键之间穿零。旧式朝世界原点平行光及其祖先有动画时，动画 GLB 暂拒绝导出以避免丢失动态追踪。
- 预览与导出共享逻辑。后台使用 Chromium 软件 WebGL，交互端可能使用 GPU，像素不承诺完全相同；MP4 还有编码色度与压缩差异。色彩管理未达到专业等级。
- 画幅支持三种居中适配，尚无自由定位、转场、代理或字幕。只使用媒体第一条音轨，导出为 48 kHz 立体声；单声道复制到左右声道。环绕声降混一致性尚未实测。预览依赖媒体元素和浏览器时钟，不保证采样精度同步；多轨大增益可能削波，暂无限幅器或响度归一化。
- 单素材 50 MB；便携包素材合计 65 MB；单任务最多 2400 帧及 5 亿像素帧，30 分钟超时；单并发队列最多 20 项。这是当前资源限制，不是性能达标证明。PNG 中间帧暂不自动回收。
- 撤销保留最近 100 步；完整命令/快照持续写入数据库，界面列出最近 100 个版本。大型项目历史和垃圾回收待优化。
- Seedance 实际生成、账号权限与计费尚未验证；本版适配文本及首帧/首尾帧生成，尚无多参考图/视频/音频、编辑延长、尾帧产物或多节点产物传递。LibTV 页面、私有接口、源码或权重均未集成为产品功能。

`smoke:animation-exchange` 可使用正式入口，实际导入动作、编辑四元数键和 Hermite 切线、撤销/重载、下载和重导入动画 GLB；比较 PNG/MP4 多个帧，确认提交后切换动作不改变任务快照。见 [动画交换记录](docs/research/2026-10-23-animation-exchange.md)。

`smoke:playback` 实际编辑同场景多动作、倒放/循环/往返、切分后的小数相位，检查撤销、重载、引用保护、任务快照和 96 帧影片。开发服务上加 `-- --renderer`，另将 14 个时刻与预定动作/源帧的直接场景渲染逐像素比较。见 [动作调度记录](docs/research/2026-10-23-playback.md)。

`smoke:layers` 实际操作对象层权重、淡入淡出、增量、通道、顺序和禁用/删除，检查撤销/重载、原动作编辑、静态 GLB、项目包与 48 帧带父子/摄影机混合和倒放的影片。开发服务上加 `-- --renderer`，另将 8 个时刻与手工计算姿态的静态场景逐像素比较，参考仍共用 Three.js 显示层。见 [对象层记录](docs/research/2026-10-23-layers.md)。

`smoke:bake` 在开发或正式入口操作烘焙范围/步长/归零/插值、取消、保存新动作、撤销/重载和 GLB 再导入；逐像素比较原始、烘焙及重导入的整帧/子帧 PNG，并对照固定快照的真实 MP4。见 [烘焙研究与运行](docs/research/2026-10-23-bake.md)。

`smoke:skin` 实际操作关节创建/父级/动画姿态、绑定/解绑、组件权重、撤销/重做/重载，导出并重导入动画和静态 GLB，比较整帧/子帧 PNG 以及固定快照影片。见 [骨架与蒙皮记录](docs/research/2026-10-23-skinning.md)。

`smoke:constraints` 实际检查约束创建/排序/影响/开关、循环拒绝、撤销恢复、约束驱动摄影机和蒙皮、静态及烘焙 GLB 重导入、固定快照影片和便携项目。见 [约束研究及运行记录](docs/research/2026-10-24-constraints.md)。

`smoke:ik` 实际检查链/控制器创建与移除、极向/影响/开关、目标关键帧与不可达提示、循环拒绝、撤销重载、烘焙启用、GLB 重导入、固定快照影片及项目包。见 [IK 研究及运行记录](docs/research/2026-10-24-ik.md)。

`smoke:ik-limits` 检查铰链/锥角编辑、参考重记、非法区间拒绝、保存撤销、GLB 与影片；`-- --no-media` 明确只检查浏览器 PNG/GLB 与编辑保存。0.15/0.16 检查时 FFmpeg/ffprobe 曾受 Windows 代码完整性策略阻止；0.17 复查同一路径工具已可执行，本轮未更改策略或替换工具，恢复原因未确认。最新媒体检查见基础姿态运行记录，历史报告保留当时事实。见 [限角研究及运行证据](docs/research/2026-10-25-ik-limits.md)。

`smoke:ik-animation` 检查影响/极向角曲线、动作与层路由、烘焙、保存恢复和输出。`smoke:rest-pose` 检查基础字段与实际手柄、补偿/不补偿、复制/重置、撤销重载、GLB 重导入、便携项目及固定快照 MP4。见 [基础姿态规格与运行](docs/research/2026-10-25-rest-pose.md)。

`smoke:ik-match` 在开发或正式入口操作双向匹配与记键、零影响 FK 的真实手柄、撤销重做/重载、覆盖层原子拒绝、GLB 重导入、项目包和固定快照 MP4。见 [FK/IK 匹配研究与运行](docs/research/2026-10-25-ik-match.md)。

`smoke:retarget` 实际配置跨骨架映射、取消分析、拒绝重叠根、生成新动作并清理跨场景选择，检查撤销/重载、动画与静态 GLB 重导入、项目包和固定快照 MP4。见 [重定向研究与运行](docs/research/2026-10-25-retarget.md)。
