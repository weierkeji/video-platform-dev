# Frameforge Studio

独立开发的三维、动画、影视剪辑与 AI 工作流平台。当前为 **0.3 基础版本**，完整目标仍是覆盖 Blender 与 LibTV 的功能范围；尚未达到专业可用、性能达标或功能完整。

已有真实能力：统一项目格式、SQLite 自动保存、跨重启撤销重做、版本审计、结构化 Agent 命令、三维对象/层级/材质编辑、顶点移动/三角面挤出/线性细分、OBJ 导入导出、变换关键帧、镜头与媒体时间轴、便携项目包、本地工作流与带音频 MP4 后台导出。Seedance 正式接口适配器、参数编辑及任务恢复已编码并通过本地协议/集成检查；当前缺少凭据，尚未验证真实供应商生成，不返回模拟生成结果。

## 启动

环境：Node.js **24.15 或以上的 24.x**、npm、Chrome/Chromium/Edge、FFmpeg 与 ffprobe。Windows 已实际运行 Node 24.20.0、Chrome 155.0.8059.82、FFmpeg 9.0.2。浏览器与 FFmpeg 由用户安装。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 **http://127.0.0.1:4173**。macOS/Linux 使用 `npm`，并按需设置 `STUDIO_BROWSER_PATH`；目前运行证据来自 Windows。

```powershell
npm.cmd run build
npm.cmd start
```

第二组使用构建产物运行。当前服务仍依赖 tsx 与 Vite 包，安装时保留开发依赖，不使用 `--omit=dev`。后端修改后需重启服务；前端由 Vite 更新。

配置见 [.env.example](.env.example)。服务读取进程环境变量，不自动读取 `.env`；PowerShell 可用 `$env:PORT='4173'`。默认数据目录 `.local/data` 包括 `studio.sqlite`、素材 `blobs/` 和任务 `renders/`。备份时先停止服务，再完整复制此目录。不要删除 `.local` 来重新安装。

0.3 使用项目格式 v3，为工作流添加生成参数。首次读取旧数据库时，先在 `backups/` 保存完整 SQLite 副本，再原子升级当前项目、撤销历史、版本及任务快照，并记录迁移。支持导入 v1/v2 包：v1 保留原有拉伸和音量，v2 保留画幅设置；不改原文件，未知格式拒绝导入。

## 使用

1. 新建项目，添加网格、摄影机或灯光。选中对象后编辑属性或使用视口手柄。`G/R/S` 切换变换，`Delete` 删除选中对象或片段。
2. 在帧 0 记录变换关键帧，移动播放头再改变属性。已有动画属性会更新当前帧关键帧。插值支持保持、线性和 smoothstep；后者不是 Bézier。
3. 镜头引用摄影机和场景。“将当前视角用于镜头”保存摄影机姿态。“成片预览”显示时间轴输出，自由编辑视角与网格不进入成片。
4. 导入图片、视频或音频后加入时间轴。在片段属性中移动、调整入点/时长/轨道，`K` 在播放头处切分。图片与视频支持完整显示、居中裁切铺满和拉伸；新片段默认完整显示。视频原声随片段入点、切分、静音和音量一起编辑；预览与导出均支持 0–2 倍增益。同轨片段不能重叠；视觉高轨覆盖低轨，未覆盖区域显示低轨，音轨混合。
5. 每次有效命令自动保存。`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做，关闭重开后仍保留。版本记录可审阅命令、恢复旧快照；Agent 命令先预览校验，再应用。
6. “导出 MP4”或运行本地工作流会提交真实任务。任务固定提交时的快照，继续编辑不影响正在导出的内容。结果可下载并登记为素材；点击“任务 → 同步导出素材”更新当前编辑器版本。
7. 保存项目包会下载含素材的 `.ffstudio` 文件；“打开”校验并导入，ID 冲突时创建副本。产物素材随包携带；完整历史与运行任务留在本机数据库。

可打开的项目与实际导出结果见 [examples](examples/README.md)。

## Seedance 工作流

在工作流中添加“文本输入”和“Seedance”并连接；生成设置保存模型 ID、对应系列、时长、分辨率、画幅、随机种子、原声和水印，以及可选的素材库首尾帧图片。点击节点上的生成按钮执行该输出；多个输出互不强制执行。结果下载、探测并登记到同一项目素材库后，可加入时间轴继续剪辑。

服务端从 `ARK_API_KEY` 读取密钥，`STUDIO_SEEDANCE_MODEL` 可提供默认模型 ID。付费生成默认关闭；确认供应商权限和预算后，由运行者在启动环境设置 `STUDIO_ENABLE_PAID_GENERATION=true`。本平台尚无金额预算控制或价格估算。配置改变后重启服务；密钥不放进项目、浏览器或日志。当前开发运行没有配置密钥或调用付费生成。

已有供应商任务 ID 的中断任务使用“恢复查询”，不重新生成；提交响应丢失时需在供应商控制台核对此次任务 ID 后关联。只有远端排队状态可请求取消，最终状态以供应商查询结果为准。失败/已取消任务的“重新生成”会创建新计费任务。详细依据和限制见 [供应商研究记录](docs/research/2026-10-22-seedance.md)。

## 当前边界

- 本地单用户、loopback 监听；无远程鉴权、协作编辑或生产部署。
- Three.js 提供 WebGL 基础组件；几何算法、项目格式、命令、求值和任务由本仓库实现，不调用 Blender / bpy。
- 只有基础三角网格建模，无雕刻、UV、骨骼、物理、节点材质、路径追踪、合成器、跟踪等。OBJ 仅支持位置、面及凸多边形扇形三角化，不保留 UV、法线、MTL 或层级。
- 预览与导出共享逻辑。后台使用 Chromium 软件 WebGL，交互端可能使用 GPU，像素不承诺完全相同；MP4 还有编码色度与压缩差异。色彩管理未达到专业等级。
- 画幅支持三种居中适配，尚无自由定位、转场、代理或字幕。只使用媒体第一条音轨，导出为 48 kHz 立体声；单声道复制到左右声道。环绕声降混一致性尚未实测。预览依赖媒体元素和浏览器时钟，不保证采样精度同步；多轨大增益可能削波，暂无限幅器或响度归一化。
- 单素材 50 MB；便携包素材合计 65 MB；单任务最多 2400 帧及 5 亿像素帧，30 分钟超时；单并发队列最多 20 项。这是当前资源限制，不是性能达标证明。PNG 中间帧暂不自动回收。
- 撤销保留最近 100 步；完整命令/快照持续写入数据库，界面列出最近 100 个版本。大型项目历史和垃圾回收待优化。
- Seedance 实际生成、账号权限与计费尚未验证；本版适配文本及首帧/首尾帧生成，尚无多参考图/视频/音频、编辑延长、尾帧产物或多节点产物传递。LibTV 页面、私有接口、源码或权重均未集成为产品功能。

## 开发与证据

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run smoke
npm.cmd run smoke:media
npm.cmd run smoke:workflow
```

`smoke` 需先启动服务，会新建检查项目，使用真实浏览器和 FFmpeg 完成编辑/保存/导出检查。`smoke:media` 需要开发服务（`npm.cmd run dev`），还会读取实际 Web Audio 输出、导出 PCM 和画面像素，核对原声、源入点、切分、增益与画幅。结果在 `.local/checks`。不调用付费服务，也不替代完整产品验收。

`smoke:workflow` 检查真实界面编辑/保存、缺少配置时拒绝提交、独立本地渲染及项目包重导入；只在付费生成未启用时运行。`tests/generation.test.ts` 使用明确的协议夹具，包含真实样例 MP4 下载流/探测/入库检查，不能当作外部模型成功生成的证据。
